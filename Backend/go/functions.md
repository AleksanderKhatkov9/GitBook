# 3. Функции

> Источники: [Спецификация — Function declarations, Calls](https://go.dev/ref/spec) · [Metanit — глава 3](https://metanit.com/go/tutorial/)

## Объявление

```go
func add(a int, b int) int {
    return a + b
}
```

Одинаковые типы параметров подряд можно записать один раз: `func add(a, b int) int`.

Функция без результата:

```go
func greet(name string) {
    fmt.Println("Привет,", name)
}
```

Аргументы передаются **копией**. Функция не меняет переменную вызывающего, если той не передан указатель (см. [Указатели](pointers.md)).

## Несколько результатов

Так в Go возвращают и значение, и ошибку. Второй результат проверяют сразу.

```go
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("деление на ноль")
    }
    return a / b, nil
}

q, err := divide(10, 2)
if err != nil {
    return err
}
```

Имена результатов можно задать заранее. Голый `return` вернёт их текущие значения. Именованный результат удобен в короткой функции; в длинной явный `return q, err` читается легче.

```go
func bounds(n int) (low, high int) {
    low = n - 1
    high = n + 1
    return
}
```

## Переменное число аргументов

`...T` собирает хвост аргументов в срез.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

sum(1, 2, 3)
```

Уже готовый срез передают с `...`: `sum(items...)`.

## Функция как значение

У функции есть тип: какие аргументы принимает и что возвращает.

```go
func apply(a, b int, op func(int, int) int) int {
    return op(a, b)
}

apply(2, 3, add)
```

## Анонимные функции и замыкания

Функцию можно объявить на месте. Она видит переменные внешней функции и держит их, пока жива сама.

```go
func counter() func() int {
    n := 0
    return func() int {
        n++
        return n
    }
}

next := counter()
fmt.Println(next()) // 1
fmt.Println(next()) // 2
```

С Go 1.22 переменная цикла в `for` создаётся заново на каждой итерации. Замыкание, запущенное внутри цикла, видит значение **этой** итерации.

## Рекурсия

Функция может вызывать себя. Нужно явное условие выхода, иначе стек кончится и программа упадёт.

```go
func fact(n int) int {
    if n <= 1 {
        return 1
    }
    return n * fact(n-1)
}
```

Для длинных цепочек на бэкенде чаще хватает цикла: он не копит кадры стека.

## Параметры типа

С Go 1.18 функция может работать с разными типами, не теряя проверки компилятора. Ограничение пишут после имени параметра типа.

```go
func first[T any](items []T) (T, bool) {
    var zero T
    if len(items) == 0 {
        return zero, false
    }
    return items[0], true
}
```

`any` — другое имя пустого интерфейса `interface{}`: «любой тип». Для чисел и операций сравнения ограничение строже, например `cmp.Ordered` из стандартной библиотеки.

Параметры типа есть и у структур. Подробнее о типах — в [следующей группе глав](types.md) и в спецификации, раздел Type parameters.
