# 3. Функции

> Источники: [Учебник — определение функций](https://docs.python.org/3/tutorial/controlflow.html#defining-functions) · [Справочник — вызовы](https://docs.python.org/3/reference/expressions.html#calls) · [Metanit — глава 2, функции](https://metanit.com/python/tutorial/)

## Объявление

```python
def add(a, b):
    return a + b

def greet(name):
    print("Привет,", name)
```

Без `return` функция возвращает `None`. `return` без значения делает то же самое и сразу выходит.

Имена параметров — локальные. Объект передаётся по ссылке: функция видит тот же объект, но присваивание параметру снаружи ничего не меняет. Метод вроде `append` меняет сам объект, и это видно вызывающему.

## Параметры

```python
def user(name, age=18, *, active=True):
    return name, age, active

user("Анна")
user("Борис", 30)
user("Вера", age=25, active=False)
```

Значение по умолчанию подставляется, если аргумент не передали. Аргумент можно передать по имени — порядок тогда не важен.

`*` в списке параметров отделяет то, что **после** него можно передать только по имени. До `*` (или до `/` в обратную сторону) бывают и позиционные параметры. Это защита от вызова `user("Анна", 18, False)`, где неочевидно, чему соответствует `False`.

Несколько лишних позиционных аргументов собирает `*args` (кортеж), именованных — `**kwargs` (словарь):

```python
def show(*args, **kwargs):
    print(args)
    print(kwargs)

show(1, 2, city="Минск")
```

## Ловушка значения по умолчанию

Значение по умолчанию считается **один раз**, в момент определения функции. Изменяемый объект там общий для всех вызовов:

```python
def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket

add_item("a")  # ["a"]
add_item("b")  # ["a", "b"] — тот же список
```

Новый список на каждый вызов создают внутри:

```python
def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

## Лямбда

`lambda` — выражение-функция без имени и без тела из нескольких строк. Один результат, `return` писать не нужно.

```python
square = lambda x: x * x
pairs = [(2, "b"), (1, "a")]
pairs.sort(key=lambda item: item[0])
```

Для длинной логики обычный `def` читается лучше.

## Преобразование типов

| Вызов | Что получает |
|-------|----------------|
| `int("42")` | `42` |
| `int(3.9)` | `3`, дробная часть отбрасывается |
| `float("1.5")` | `1.5` |
| `str(20)` | `"20"` |
| `bool(0)` | `False` |
| `list("ab")` | `["a", "b"]` |

Неверная строка (`int("x")`) — `ValueError`.

## Область видимости

Имя ищут по цепочке **LEGB**: локальная область функции, затем объемлющие функции, затем модуль, затем встроенные имена (`print`, `len`).

Присваивание внутри функции делает имя локальным на всю функцию. Читать глобальное имя можно, присваивать ему — только с `global`. Имя объемлющей функции (не модуля) меняют через `nonlocal`.

```python
count = 0

def inc():
    global count
    count += 1
```

## Замыкание

Вложенная функция помнит имена внешней, даже после того как внешняя завершилась:

```python
def make_adder(n):
    def add(x):
        return x + n
    return add

plus3 = make_adder(3)
plus3(10)  # 13
```

В цикле все лямбды видят **одно** имя. К моменту вызова оно уже равно последнему значению:

```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)

funcs[0]()  # 2, не 0
```

Нужное значение фиксируют аргументом по умолчанию: `lambda i=i: i`. Он считается на каждой итерации.

## Декоратор

Декоратор — функция, которая принимает функцию и возвращает другую, обычно обёртку.

```python
def twice(fn):
    def wrapper(*args, **kwargs):
        fn(*args, **kwargs)
        return fn(*args, **kwargs)
    return wrapper

@twice
def hello(name):
    print("Привет,", name)
```

`@twice` над `def` означает `hello = twice(hello)`. Вызов `hello("Анна")` печатает приветствие дважды: так устроена обёртка, а не сам язык.
