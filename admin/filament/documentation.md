## Что такое Filament

**Filament** — Server-Driven UI (SDUI) фреймворк для Laravel. UI описывается на PHP, а не в шаблонах: сервер динамически формирует интерфейс по конфигурации и бизнес-логике. Это отличает SDUI от обычного server-rendered UI на статичных Blade-шаблонах.

Тысячи разработчиков используют Filament для админ-панелей, но фреймворк подходит и для дашбордов, CRM, пользовательских порталов и multi-panel приложений.
