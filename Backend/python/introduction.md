## Что такое Python

Python читает исходный текст и выполняет его. Основная реализация — **CPython**: она компилирует файл в байткод и прогоняет его на виртуальной машине. Отдельной стадии «собрать бинарник и разложить по серверам» для обычной программы нет.

Тип у значения, а не у имени. Имя `count` сегодня может указывать на число, завтра — на строку. Проверка типа происходит в момент операции: сложить число и строку без явного преобразования нельзя.

Блок кода — это **отступ**, а не фигурные скобки. Уровень вложенности виден по левому краю.

Исходный текст по умолчанию в **UTF-8**. Заглавные и строчные буквы — разные символы: `User` и `user` — два разных имени.

## Установка

Сборка под свою систему: [python.org/downloads](https://www.python.org/downloads/). На Windows при установке отметьте **Add python.exe to PATH**, иначе команда из терминала не найдётся.

```bash
python --version
```

Если сработала только `python3`, дальше в командах подставляйте её.

| Команда | Что делает |
|---------|------------|
| `python script.py` | Выполнить файл |
| `python` | Открыть интерактивный режим (REPL) |
| `python -m venv .venv` | Создать виртуальное окружение в папке `.venv` |
| `python -m pip install имя` | Поставить пакет в текущее окружение |

Онлайн, без установки: [python.org/shell](https://www.python.org/shell/).

## Первая программа

Файл `hello.py`:

```python
print("Привет, Python")
```

```bash
python hello.py
```

`print` выводит аргументы в стандартный поток и переводит строку. Точка с запятой между инструкциями не нужна: одна инструкция — одна строка. Несколько инструкций в одной строке разделяют `;`, так почти не пишут.

## REPL

```text
>>> 2 + 2
4
>>> name = "Анна"
>>> name
'Анна'
```

`>>>` — приглашение. Выражение без присваивания REPL печатает сам. Выход: `exit()` или Ctrl+Z и Enter в Windows, Ctrl+D в macOS и Linux.

## Отступы и комментарии

Тело функции, цикла и условия сдвигается вправо. Принятый шаг — **4 пробела**. Смешивать пробелы и табы в одном блоке нельзя: интерпретатор откажется разбирать файл.

```python
def greet(name):
    # комментарий до конца строки
    print("Привет,", name)
```

Строка с `#` — комментарий. Документацию функции пишут строкой сразу под `def` — это docstring, её читает `help()`.
