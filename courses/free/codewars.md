# Codewars

> Сайт: [codewars.com](https://www.codewars.com/)

Платформа с короткими задачами (**kata**). Ранги от 8 kyu (новичок) до 1 kyu и дан. Решения в браузере, тесты (TDD), сравнение с чужими подходами.

Бесплатна для обучения; 55+ языков, включая JavaScript, PHP, Python, TypeScript.

## Зачем использовать

| Цель | Как |
|------|-----|
| Разогрев перед LeetCode | Короткие kata, быстрая обратная связь |
| Требование RS School | Уровень 8–7 kyu перед основным курсом |
| Новый язык | Та же задача на другом языке |
| Сообщество | Разборы и альтернативные решения после сдачи |

## Ранги (kyu)

| Уровень | Смысл |
|---------|--------|
| 8–7 kyu | Начало: циклы, массивы, строки |
| 6–5 kyu | Средний: алгоритмы, структуры |
| 4–1 kyu | Сложные задачи |
| Dan | Экспертный уровень |

## С чего начать

1. Зарегистрируйтесь на [codewars.com](https://www.codewars.com/).
2. Выберите язык (например, JavaScript или PHP).
3. Решайте с **8 kyu** → цель для старта RS School: стабильные **8–7 kyu**.
4. После прохождения смотрите чужие решения — учитесь коротким идиомам.
