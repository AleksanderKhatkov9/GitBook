# Основы синтаксиса

> Источник: [Основы синтаксиса | PHP Manual](https://www.php.net/manual/ru/language.basic-syntax.php)

## PHP-теги

Код PHP выполняется внутри тегов:

```php
<?php
echo "Hello";
?>
```

| Тег | Описание |
|-----|----------|
| `<?php ... ?>` | Стандартный тег (рекомендуется) |
| `<?= ... ?>` | Короткий echo-тег: `<?= $name ?>` ≡ `<?php echo $name; ?>` |

В файлах, содержащих **только** PHP-код, закрывающий `?>` обычно опускают — так меньше риска лишних пробелов/переносов в ответе.

## Инструкции

Инструкции разделяются точкой с запятой:

```php
<?php

echo "одна";
echo "две";
```

Блок `{ ... }` группирует инструкции (условия, циклы, функции, классы).

## Комментарии

```php
<?php

// Однострочный комментарий

# Тоже однострочный

/*
 * Многострочный
 * комментарий
 */

/**
 * DocBlock — для IDE и phpDocumentor
 * @param string $name
 */
function greet(string $name): void {}
```

## Выход из режима PHP

Между тегами PHP можно писать HTML:

```php
<?php if ($loggedIn): ?>
  <p>Добро пожаловать</p>
<?php else: ?>
  <p>Войдите</p>
<?php endif; ?>
```

Альтернативный синтаксис (`if:`, `endif;`) удобен в шаблонах. Подробнее: [Управляющие конструкции](control-structures.md).

## Чувствительность к регистру

| Элемент | Регистр |
|---------|---------|
| Переменные (`$Name` ≠ `$name`) | Чувствительны |
| Функции, классы, константы классов | Нечувствительны к регистру (но пишите единообразно) |
| Константы через `define` / `const` | По умолчанию чувствительны |

```php
<?php

$foo = 1;
$Foo = 2; // другая переменная

function Hello() {}
hello(); // вызовет Hello() — имена функций нечувствительны к регистру
```
