# Fullscreen

> Официальная документация: [Fullscreen | AdminLTE 4](https://adminlte.io/themes/v4/docs/javascript/fullscreen.html)

Плагин переключает полноэкранный режим для элемента или всей страницы.

## Разметка

```html
<a class="nav-link" href="#" data-lte-toggle="fullscreen" role="button">
  <i class="bi bi-arrows-fullscreen"></i>
</a>
```

По клику элемент разворачивается на весь экран (Full Screen API браузера).

## Ограничения

- Требуется жест пользователя (click) — autoplay fullscreen блокируется браузером.
- Не все мобильные браузеры поддерживают Fullscreen API одинаково.
