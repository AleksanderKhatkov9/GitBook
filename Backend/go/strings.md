# 7. Строки

> Источники: [Спецификация — String literals, Rune literals](https://go.dev/ref/spec) · [Пакет strings](https://pkg.go.dev/strings) · [Metanit — глава 7](https://metanit.com/go/tutorial/)

Строка — неизменяемая последовательность **байт**. Текст в ней обычно закодирован в UTF-8. Один символ Unicode (руна, тип `rune`) может занимать от 1 до 4 байт.

## Литералы

```go
s := "строка\n"          // интерпретируемая: \n, \t, \", \\, \u0410
raw := `C:\temp\notes`   // сырая: обратные кавычки, без escape
```

Изменить символ внутри строки нельзя. «Изменение» — это новая строка: конкатенация `a + b` или `strings.Builder`, если кусков много.

## Байты и руны

`len(s)` считает байты, не символы. Индекс `s[i]` — один байт. Латинские буквы без диакритики занимают один байт, кириллица — два.

```go
s := "Go язык"
fmt.Println(len(s))                          // байты
fmt.Println(utf8.RuneCountInString(s))       // руны

for i, r := range s {                        // i — байтовый индекс, r — руна
    fmt.Printf("%d %c\n", i, r)
}
```

Руна-литерал пишется в одинарных кавычках: `'Я'`. Это число (код символа), не строка.

Пакет `unicode/utf8` проверяет, что байты — корректный UTF-8 (`ValidString`), и разбирает строку по рунам.

## Пакет strings

Импорт: `import "strings"`. Функции не меняют исходную строку, они возвращают новую.

| Функция | Зачем |
|---------|--------|
| `Contains`, `HasPrefix`, `HasSuffix` | Есть ли подстрока, начало, конец |
| `Index`, `LastIndex` | Позиция в байтах или `-1` |
| `Split`, `Join`, `Fields` | Разрезать и собрать; `Fields` режет по пробелам |
| `Replace`, `ReplaceAll` | Замена |
| `ToLower`, `ToUpper`, `TrimSpace` | Регистр и края |
| `Trim`, `TrimPrefix`, `TrimSuffix` | Срезать набор символов или точный край |
| `Count`, `Repeat` | Сколько вхождений; повторить строку |

```go
parts := strings.Split("a,b,c", ",")
line := strings.Join(parts, " | ")
name := strings.TrimSpace("  Анна  ")
```

Много склеек в цикле собирайте через `strings.Builder`: он копирует байты в растущий буфер, а не создаёт новую строку на каждом `+`.

## Числа и строки

Пакет `strconv` переводит туда и обратно. `fmt.Sprintf` тоже умеет, но для разбора входных данных берите `strconv`: ошибка там явная.

```go
n, err := strconv.Atoi("42")
s := strconv.Itoa(42)
```

`Atoi` — частный случай `ParseInt` для базы 10 и типа `int`.
