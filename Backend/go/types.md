# 5. Структуры и коллекции

> Источники: [Спецификация — Types, Composite literals, Selectors](https://go.dev/ref/spec) · [Metanit — глава 5](https://metanit.com/go/tutorial/)

Глава про типы, которые собирают из базовых: свои имена, структуры, методы, срезы и карты.

## Свои имена типов

```go
type UserID int64          // новый тип: свои методы, с int64 напрямую не смешивается
type ID = int64            // псевдоним: то же самое, что int64
```

`UserID` и `int64` нужно преобразовывать явно: `UserID(n)`. Псевдоним `ID` взаимозаменяем с `int64`. Псевдонимы уже заняты в языке: `byte`, `rune`, `any`.

## Структуры

```go
type User struct {
    Name string
    Age  int
}

u := User{Name: "Анна", Age: 20}
fmt.Println(u.Name)
u.Age = 21
```

Поля с заглавной буквы видны другим пакетам. С маленькой — только внутри своего пакета.

Структура может вкладываться в другую. Если вложить тип **без имени поля**, его поля и методы поднимаются наружу:

```go
type Timestamps struct {
    CreatedAt time.Time
}

type Post struct {
    Timestamps
    Title string
}

p := Post{Title: "Заметка"}
p.CreatedAt = time.Now()
```

## Методы

Метод — функция с получателем перед именем. Получатель — значение или указатель.

```go
func (u User) Greet() string {
    return "Привет, " + u.Name
}

func (u *User) Birthday() {
    u.Age++
}
```

`Greet` работает с копией. `Birthday` меняет исходную структуру: получатель — указатель. Вызов выглядит одинаково, адрес компилятор возьмёт сам, если переменная адресуемая:

```go
u := User{Name: "Анна", Age: 20}
fmt.Println(u.Greet())
u.Birthday()
```

Правило на каждый день: метод, который меняет получателя или не должен копировать большую структуру, объявляют с `*T`. Остальные методы того же типа тоже делают с `*T`, чтобы набор методов был один.

## Срезы

Срез — окно в массив: указатель на данные, длина и вместимость. Длину можно увеличивать через `append`. Тип среза — `[]T`, без числа в скобках.

```go
nums := []int{1, 2, 3}
nums = append(nums, 4)
fmt.Println(nums[0], len(nums), cap(nums))

part := nums[1:3] // элементы с индекса 1 до 3, не включая 3
```

`make` задаёт длину и при необходимости вместимость:

```go
buf := make([]byte, 0, 64)
```

`append` может выделить новый массив, если места не хватило, и вернуть уже другой срез. Результат всегда сохраняйте: `nums = append(nums, 4)`.

Срез, который никуда не записали (`var s []int`), равен `nil`. Длина и вместимость у него нулевые, `append` с ним работает. Это нормальное пустое состояние, отдельно от «пустой, но не nil» `[]int{}`.

Общая память: `part` смотрит в тот же массив, что и `nums`. Запись в `part[0]` меняет и `nums`. Копию данных даёт встроенный `copy` или выражение `append([]int(nil), nums...)`.

Вырезать элемент по индексу `i`: `append(nums[:i], nums[i+1:]...)`.

## Карты

Карта — набор пар ключ/значение. Ключ должен быть сравниваемым (`==`): числа, строки, указатели, структуры из сравниваемых полей. Срез ключом быть не может.

```go
ages := map[string]int{
    "Анна": 20,
}
ages["Борис"] = 31

n, ok := ages["Анна"]
if ok {
    fmt.Println(n)
}

delete(ages, "Борис")
```

Чтение отсутствующего ключа возвращает нулевое значение и не падает. Отличить «лежит ноль» от «ключа нет» можно только вторым результатом `ok`.

Нулевая карта (`var m map[string]int`) читается, но запись в неё — `panic`. Создайте её литералом или `make(map[string]int)`.

Порядок обхода `range` по карте **не фиксирован**. На него нельзя опираться.

Пакеты `slices` и `maps` (с Go 1.21) закрывают частые операции: сортировка, поиск, клонирование, сравнение.
