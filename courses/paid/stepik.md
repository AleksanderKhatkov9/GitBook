# Stepik — платные курсы

> Каталог: [stepik.org/catalog](https://stepik.org/catalog)

На [Stepik](https://stepik.org/) платные курсы и **программы** (наборы из нескольких курсов): веб-разработка, Python, DevOps, анализ данных, QA и др. Часто есть скидки, сертификаты и курсы с поддержкой.

## Как искать

1. Откройте [каталог](https://stepik.org/catalog).
2. Выберите тему или воспользуйтесь поиском.
3. Смотрите цену, длительность и наличие сертификата / поддержки.

Фильтры: язык, **с сертификатами**, категории и программы курсов.

## Популярные направления

| Направление | Примеры |
|-------------|---------|
| [Веб-разработка](https://stepik.org/catalog?q=%D0%B2%D0%B5%D0%B1) | Frontend / fullstack |
| [Python](https://stepik.org/catalog?q=Python) | С нуля, логирование, геймерский Python |
| [DevOps](https://stepik.org/catalog?q=DevOps) | Linux, сети, автоматизация |
| [SQL / данные](https://stepik.org/catalog?q=SQL) | SQL с нуля, анализ данных |
| [Программы курсов](https://stepik.org/catalog) | Go-разработчик, AI-Engineer и др. |
| [Курсы с поддержкой](https://stepik.org/catalog) | Обратная связь и сопровождение |

Цены зависят от автора и акции — актуальные смотрите в [каталоге](https://stepik.org/catalog).
