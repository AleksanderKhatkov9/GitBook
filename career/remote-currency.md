# Поиск валютной удалёнки

> **Видео:** [ПРАКТИЧЕСКИЙ ГАЙД. Часть 1](https://www.youtube.com/watch?v=IdNkGSYOvqo) · [Часть 2](https://www.youtube.com/watch?v=OFk35cQPvZQ)

**Валютная удалёнка** — удалённая работа с оплатой в иностранной валюте (чаще USD / EUR), обычно в зарубежных или международных компаниях.

Цель страницы — быстрый чеклист: где искать, как фильтровать, что подготовить.

## Что нужно заранее

| Пункт | Минимум |
|-------|---------|
| **Стек** | 1–2 сильных направления (например Laravel + Vue / React / Next) |
| **GitHub** | 2–3 нормальных проекта с README, без мусорных репозиториев |
| **Резюме (CV)** | 1 страница на английском + короткая версия на русском |
| **LinkedIn** | Актуальный профиль, фото, headline с ролью и стеком |
| **Английский** | B1+ для переписки; B2 удобнее для созвонов |
| **Выплаты** | Аккаунт [Wise](https://wise.com/) / [Payoneer](https://www.payoneer.com/) (или аналог) |


См. также: [English](../english/README.md), [Algorithm](../algorithm/README.md), [GitHub / PR](../git/pull-request.md).

## Как искать эффективнее

### Ключевые слова

```
remote laravel
remote php developer
remote full stack
remote react / next.js
worldwide remote
async remote
contractor / B2B
```

Полезные уточнения в описании вакансии:

- `USD` / `EUR` / `$` / `€`
- `payroll` / `contractor` / `B2B`
- `async` / `timezone flexible`
- `Europe` / `EEA` / `worldwide`

### Фильтры, которые экономят время

| Фильтр | Зачем |
|--------|-------|
| Remote only | Отсечь офис |
| Location: Worldwide / Europe | Часто важны timezone и право найма |
| Salary range | Сразу отсечь заниженные ставки |
| Experience mid+ | Если вы не junior — не тратить отклики на junior-роли |

### Темп откликов

1. **Ежедневно 30–60 мин** — новые вакансии на 2–3 бордах + LinkedIn  
2. **5–10 качественных откликов** лучше, чем 50 шаблонных  
3. В письме / cover: **стек + 1 релевантный проект + timezone**

## Резюме и профиль

### CV (EN)

Кратко:

- Role + years (например: *Backend Developer (PHP / Laravel), 3+ years*)
- Stack: языки, фреймворки, БД, DevOps-минимум
- 2–3 проекта: задача → ваш вклад → результат (метрика, если есть)
- Ссылки: GitHub, LinkedIn, демо / сайт
- Без воды: «responsible for», «team player» без фактов

### LinkedIn headline (примеры)

```
Laravel / PHP Developer | Remote | Vue · MySQL · Docker
Full-Stack Developer (Laravel + React) | Open to remote USD/EUR
```

### Cover / первое сообщение

Шаблон на 4–6 строк:

1. Кем вы и сколько опыта  
2. Почему именно эта вакансия (1 конкретная деталь)  
3. Стек совпадает с JD  
4. Ссылка на CV / GitHub  
5. Timezone и формат (full-time remote / part-time / contract)

## Собеседования и деньги

| Этап | Что обычно бывает |
|------|-------------------|
| HR / recruiter | Английский, опыт, ожидания по зарплате, timezone |
| Tech screen | Live coding / take-home / разбор проекта |
| System / architecture | Для mid+ |
| Offer | Gross / net, валюта, налоги, оборудование, PTO |

**Зарплатные ожидания:** называйте вилку в **той же валюте**, что в вакансии (USD/EUR). Смотрите ориентиры на Levels.fyi, Glassdoor, локальные зарплатные отчёты (DOU и др.) — с поправкой на remote и ваш грейд.

**Контракт:** уточните:

- сотрудник (employment) или contractor (B2B / ИП / самозанятость)
- кто платит налоги
- срок notice period
- NDA / IP assignment

## Выплаты

| Способ | Комментарий |
|--------|-------------|
| **Wise** | Удобно для USD/EUR → локальный счёт |
| **Payoneer** | Часто у фриланс- и outstaff-компаний |
| **Банк / SWIFT** | Дороже комиссии, дольше |
| **Крипто** | Редко; только если вы сами согласны на риски |

Перед оффером спросите: *как платят, в какой валюте, раз в месяц или два раза, кто покрывает комиссии*.

---

## Красные флаги

- Просят оплатить «обучение», «оборудование» или «страховку» заранее  
- Нет нормального описания задач / компании  
- Обещают «очень много» без собеседования  
- Только мессенджер, без сайта / LinkedIn компании  
- Просят паспорт / сканы до оффера без необходимости
