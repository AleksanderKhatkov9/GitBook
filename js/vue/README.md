# Vue.js

> Официальная документация: [vuejs.org](https://vuejs.org/)

Vue — прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов.

## Быстрый старт

```bash
npm create vue@latest my-vue-app
cd my-vue-app
npm install
npm run dev
```

Приложение: [http://localhost:5173](http://localhost:5173)

## Основные концепции

- Компоненты (`.vue` файлы)
- Реактивность (`ref`, `reactive`)
- Vue Router — маршрутизация
- Pinia — управление состоянием
