# 5. Модальные глаголы

> [GrammarWay — Модальные глаголы](https://grammarway.com/ru/) · [English Grammar in Use](https://www.hasanboy.uz/wp-content/uploads/2017/11/English-grammar-in-Use.pdf)

Модальные: **модальный + V (без to)**. Нет *-s* в 3-м лице, нет инфинитива/герундия у самого модального.

```
She can swim.     ✓
She cans swim.    ✗
She can to swim.  ✗
```

---

## Обзор

| Modal | Основной смысл | Пример |
|-------|----------------|--------|
| **can / could** | умение, разрешение, просьба | Can you help? |
| **may / might** | разрешение, вероятность | It might rain. |
| **must** | сильная необходимость / вывод | You must stop. |
| **have to** | обязанность (внешняя) | I have to work. |
| **should / ought to** | совет | You should rest. |
| **shall** | предложение (BrE), формально | Shall we start? |
| **will / would** | будущее, вежливость, привычка | Would you like…? |
| **need** | необходимость | You needn't go. |
| **dare** | осмелиться | How dare you… |
| **had better** | настоятельный совет | You'd better hurry. |
| **to be to** | по плану / приказу | You are to report at 9. |

---

## Can и Could

| Значение | Пример |
|----------|--------|
| Умение | I can code in PHP. |
| Разрешение | Can I open the window? |
| Возможность | It can be cold in winter. |
| Просьба | Could you send the file? (вежливее) |
| Прошлое умение | I could swim when I was five. |

Отрицание: *can't / cannot*, *couldn't*.

Альтернатива умению в прошлом (одноразово): *was/were able to*.

---

## May и Might

| Значение | Пример |
|----------|--------|
| Разрешение (формально) | May I come in? |
| Вероятность | She may be late. / It might break. |

*might* — чуть менее вероятно, чем *may* (в повседневной речи часто взаимозаменяемы).

---

## Must / Have to

| | must | have to |
|--|------|---------|
| Смысл | внутреннее «надо» / правило говорящего; логический вывод | внешнее правило, расписание, закон |
| Пример | You must see this bug. | I have to wear a badge. |
| Отрицание | **mustn't** = запрет | **don't have to** = не обязательно |

```
You mustn't touch that.     ← нельзя
You don't have to come.     ← можно не приходить
She must be at home — the lights are on.  ← вывод
```

Прошлое обязанности: *had to* (не *musted*).

---

## Should и Ought to

Совет, рекомендация, «следовало бы».

```
You should learn Git.
You ought to check the logs.
You shouldn't ignore errors.
I should have tested that.   ← сожаление о прошлом
```

---

## Need

| Форма | Пример |
|-------|--------|
| как модальный (редко, BrE) | Need I say more? You needn't worry. |
| как обычный глагол | Do you need to go? I don't need to go. |

---

## Shall / Will / Would

| Форма | Использование |
|-------|---------------|
| shall we / I…? | предложение действия (BrE) |
| will | будущее, обещание, отказ (*won't*) |
| would | вежливые просьбы, гипотезы, привычки в прошлом |

```
Shall we deploy now?
Would you mind waiting?
When I was a kid, I would play outside every day.
```

---

## Had better

Сильный совет / предупреждение (сейчас или скоро).

```
You'd better save your work.
You'd better not be late.
```

≠ *had* в Past Perfect — это устойчивая конструкция.

---

## To be to

По договорённости, расписанию, приказу.

```
The meeting is to start at noon.
You are not to leave the building.
```

---

## Dare

```
How dare you say that!
I daren't ask. / I don't dare to ask.
```

---

## Краткая шпаргалка: обязанность

| Степень | Форма |
|---------|-------|
| Запрет | mustn't / can't |
| Сильная обязанность | must / have to |
| Совет | should / ought to / had better |
| Нет обязанности | don't have to / needn't |
