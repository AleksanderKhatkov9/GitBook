# LeetCode

> Сайт: [leetcode.com](https://leetcode.com/)

Платформа для практики алгоритмов и подготовки к техническим собеседованиям. Задачи с уровнями Easy / Medium / Hard, встроенный редактор, тесты и обсуждения решений.

Бесплатно доступна большая часть задач; Premium — доп. компании и разборы.

## Зачем использовать

| Цель | Как |
|------|-----|
| Подготовка к собеседованиям | Типовые задачи FAANG и других компаний |
| Алгоритмы и структуры данных | Массивы, деревья, графы, DP, жадные алгоритмы |
| Несколько языков | JS, PHP, Python, TypeScript, Java и др. |

## С чего начать

1. Зарегистрируйтесь на [leetcode.com](https://leetcode.com/).
2. Начните с **Easy** (массивы, строки, хеш-таблицы).
3. Цель: 1 задача в день → затем Medium.
4. После решения сравнивайте подходы в Discussions / Solutions.
