## Степени сравнения (Degrees of comparison)

### Короткие прилагательные (1–2 слога)

| Positive | Comparative | Superlative |
|----------|-------------|-------------|
| fast | faster | the fastest |
| big | bigger | the biggest |
| happy | happier | the happiest |

### Длинные прилагательные

| Positive | Comparative | Superlative |
|----------|-------------|-------------|
| useful | more useful | the most useful |
| interesting | more interesting | the most interesting |

### Исключения

| Positive | Comparative | Superlative |
|----------|-------------|-------------|
| good | better | the best |
| bad | worse | the worst |
| far | farther/further | the farthest/furthest |
| little | less | the least |
| many/much | more | the most |

```
This build is faster than the last one.
This is the most important fix.
She is as tall as her brother.
```

Наречия: *fast → faster → fastest*; *carefully → more carefully → most carefully*; *well → better → best*.

## Окончание -s / -es

| Случай | Пример |
|--------|--------|
| 3-е лицо Present Simple | He works. |
| Мн. число существительных | books, boxes |
| Притяжательный 's | Tom's laptop |

Произношение *-s*: /s/ (*cats*), /z/ (*dogs*), /ɪz/ (*watches*).

---

## Окончание -ed

| Случай | Пример |
|--------|--------|
| Past Simple правильных | worked, started |
| Past Participle | a finished task |
| Прилагательные | bored, interested |

Произношение *-ed*: /t/ (*worked*), /d/ (*played*), /ɪd/ (*wanted*, *needed*).

Правописание:

| Правило | Пример |
|---------|--------|
| e → +d | like → liked |
| согласная + y → ied | study → studied |
| CVC, ударный слог → удвоение | stop → stopped |

---

## Окончание -ing

| Случай | Пример |
|--------|--------|
| Continuous | is working |
| Герундий | I like coding |
| Причастие / прилагательное | a boring meeting |

Правописание:

| Правило | Пример |
|---------|--------|
| немое e → убрать e | write → writing |
| CVC → удвоение | run → running |
| ie → ying | die → dying |

## Притяжательный падеж

| Форма | Когда | Пример |
|-------|-------|--------|
| 's | ед. число; мн. без -s | the girl's PC, children's room |
| s' | мн. на -s | the developers' room |
| of | вещи, длинные фразы | the end of the file |
