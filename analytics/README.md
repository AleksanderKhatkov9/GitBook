# Аналитика

> Счётчики и веб-аналитика: [Яндекс Метрика](yandex.md) · [Google Analytics](google.md) · [Matomo](matomo.md)

Веб-аналитика — сбор и анализ данных о посетителях сайта: трафик, поведение, конверсии. Нужна, чтобы понимать, откуда приходят пользователи и что делать с продуктом.

## Сравнение

| | Яндекс Метрика | Google Analytics 4 | Matomo |
|--|----------------|--------------------|--------|
| **Регион** | RU / CIS | Глобально | Любой |
| **Хостинг** | Облако Яндекса | Облако Google | Свой сервер или облако |
| **Бесплатно** | Да (лимиты) | Да | Self-hosted — да |
| **Сильные стороны** | Вебвизор, карты кликов, RU-аудитория | Экосистема Google, Ads | Приватность, полный контроль |
| **GDPR / данные** | Данные у Яндекса | Данные у Google | Данные у вас |

## Когда что выбирать

```
Сайт для России / СНГ              → Яндекс Метрика (+ опционально GA4)
Международный / Ads / Search       → Google Analytics 4
Нужен контроль данных / GDPR       → Matomo (self-hosted)
Максимум покрытия RU + мир         → Метрика + GA4
```

## Общие принципы

1. **Один счётчик на layout** — код в общем шаблоне (Blade, `_document`, layout), не на каждой странице вручную.
2. **Цели и события** — сырой трафик мало полезен; настройте конверсии (форма, покупка, клик).
3. **Согласие на cookies** — для EU/EEA нужна cookie banner и условная загрузка скриптов.
4. **Не дублируйте** — два одинаковых счётчика искажают статистику.

## Быстрый чеклист

- [ ] Счётчик вставлен в layout (перед `</head>` или `</body>` по инструкции сервиса)
- [ ] Проверка: real-time / онлайн-посетители после открытия сайта
- [ ] Цели или ключевые события настроены
- [ ] Фильтр своего IP / внутренний трафик (по возможности)
- [ ] Связь с Search Console / Вебмастером (для SEO)
