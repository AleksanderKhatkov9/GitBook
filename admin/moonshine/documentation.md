## Что такое MoonShine

**MoonShine** — open-source пакет (лицензия MIT) для проектов на **Laravel**, предназначенный для ускоренной разработки web-проектов. Подходит для:

- админ-панелей;
- MVP (минимально жизнеспособных продуктов);
- backoffice-приложений;
- систем управления контентом (CMS).

MoonShine работает как «framework on framework» и расширяет возможности Laravel.

### Особенности

| Особенность | Описание |
|-------------|----------|
| Гибкость | Нет жёсткой привязки к моделям, можно использовать любые источники данных |
| Конструктор UI | Удобные инструменты для создания форм и таблиц |
| Alpine.js | Легковесный frontend-функционал |
| TailwindCSS + Blade | Привычный стек для Laravel-разработчиков |
| Расширяемость | Поддержка Blade и Livewire-компонентов |
| Кастомизация | Конструктор шаблонов, Color Manager, смена дизайна |
