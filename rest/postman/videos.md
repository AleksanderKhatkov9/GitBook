# Видео по Postman и REST API

Подборка YouTube-уроков по работе с Postman: от первого запроса до коллекций, тестов и автоматизации.

## Рекомендуемый порядок

1. [Основы REST](rest-basics.md) в этой книге
2. [Установка Postman](installation.md) → [Быстрый старт](quick-start.md)
3. Видео ниже — начните с [полного гайда](https://www.youtube.com/watch?v=KdCAV4SzvqQ), затем углубляйтесь в тесты и Collection Runner
