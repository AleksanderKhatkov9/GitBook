# Python

**Python** — интерпретируемый язык общего назначения. Типы проверяются во время выполнения, блоки кода задаёт отступ, а стандартная библиотека закрывает файлы, сеть, даты и тесты без отдельного фреймворка.

> [Документация Python](https://www.python.org/doc/) · [Учебник](https://docs.python.org/3/tutorial/) · [Справочник языка](https://docs.python.org/3/reference/) · [Metanit — руководство по Python](https://metanit.com/python/tutorial/)

Этот раздел — сжатый справочник по основам: главы 1–8 Metanit и учебник с [python.org/doc](https://www.python.org/doc/). Формулировки свои, источник истины по синтаксису — справочник языка. Примеры короткие: их нужно читать и запускать, а не копировать пакетом.

Файлы, даты и параллельность (главы 9–11 Metanit) сюда не входят.

## Чем Python удобен

| Свойство | На практике |
|----------|-------------|
| Короткий код | Идея проверяется в нескольких строках |
| Динамическая типизация | Имя можно связать с объектом любого типа, явного объявления нет |
| Батарейки в комплекте | `json`, `sqlite3`, `pathlib`, `unittest` уже установлены |
| Один стиль | [PEP 8](https://peps.python.org/pep-0008/) задаёт отступы, имена и длину строки |
| REPL | `python` без файла — сразу проверить выражение |

## Требования

- Python 3 с [python.org/downloads](https://www.python.org/downloads/). В терминале: `python --version` или `python3 --version`
- Редактор с поддержкой Python (PyCharm или VS Code / Cursor с расширением Python)

`match` из [главы 9](match.md) есть начиная с Python 3.10.
