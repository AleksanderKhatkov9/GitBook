# Card Widget

> Официальная документация: [Card Widget | AdminLTE 4](https://adminlte.io/themes/v4/docs/javascript/card-widget.html)

Плагин для сворачивания и удаления карточек в контенте.

## Сворачивание

```html
<div class="card">
  <div class="card-header">
    <h3 class="card-title">Заголовок</h3>
    <div class="card-tools">
      <button type="button" class="btn btn-tool" data-lte-toggle="card-collapse">
        <i class="bi bi-dash"></i>
      </button>
    </div>
  </div>
  <div class="card-body">...</div>
</div>
```

## Удаление карточки

```html
<button type="button" class="btn btn-tool" data-lte-toggle="card-remove">
  <i class="bi bi-x"></i>
</button>
```
