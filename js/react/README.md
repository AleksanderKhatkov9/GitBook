# React

> Официальная документация: [react.dev](https://react.dev/)

React — библиотека для построения пользовательских интерфейсов на JavaScript.

## Быстрый старт

```bash
npx create-react-app my-app
cd my-app
npm start
```

Приложение: [http://localhost:3000](http://localhost:3000)

## Основные концепции

- Компоненты и JSX
- Хуки (`useState`, `useEffect`)
- Props и состояние
- React Router — маршрутизация
