# Другие бесплатные платформы

Дополнительно к [LeetCode](leetcode.md) и [Codewars](codewars.md) — бесплатные курсы и практика по коду.

## Практика и задачи

| Платформа | Описание | Ссылка |
|-----------|----------|--------|
| [HackerRank](https://www.hackerrank.com/) | Задачи, треки по языкам и SQL, подготовка к собеседованиям | [hackerrank.com](https://www.hackerrank.com/) |
| [Exercism](https://exercism.org/) | Упражнения + менторский код-ревью от сообщества | [exercism.org](https://exercism.org/) |
| [Codeforces](https://codeforces.com/) | Спортивное программирование, контесты | [codeforces.com](https://codeforces.com/) |

## Курсы и треки (бесплатно)

| Платформа | Описание | Ссылка |
|-----------|----------|--------|
| [freeCodeCamp](https://www.freecodecamp.org/) | Полные бесплатные курсы: веб, JS, backend, сертификаты | [freecodecamp.org](https://www.freecodecamp.org/) |
| [The Odin Project](https://www.theodinproject.com/) | Полный путь fullstack (HTML → JS → Node/React), проектный подход | [theodinproject.com](https://www.theodinproject.com/) |
| [Frontend Mentor](https://www.frontendmentor.io/) | Реальные макеты для вёрстки (есть бесплатные челленджи) | [frontendmentor.io](https://www.frontendmentor.io/) |

## Как выбрать

| Ситуация | Куда идти |
|----------|-----------|
| Алгоритмы / собеседования | [LeetCode](leetcode.md), [HackerRank](https://www.hackerrank.com/) |
| Лёгкий старт, kata | [Codewars](codewars.md), [Exercism](https://exercism.org/) |
| Учиться веб с нуля | [freeCodeCamp](https://www.freecodecamp.org/), [The Odin Project](https://www.theodinproject.com/), [RS School](rs-school.md) |
| Практика вёрстки по макетам | [Frontend Mentor](https://www.frontendmentor.io/) |
| Спортивное программирование | [Codeforces](https://codeforces.com/) |
