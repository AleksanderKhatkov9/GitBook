# RS School — JS / Frontend

> Источник: [rolling-scopes-school/tasks](https://github.com/rolling-scopes-school/tasks/blob/master/README.md)  
> Сайт: [RS School](https://rs.school/)

Бесплатный курс сообщества [The Rolling Scopes](https://rollingscopes.com/). С 2013 года — обучение JavaScript / Front-end. Новый набор каждый год (~6000–7000 студентов), помогают 250+ менторов.

**Цель:** знания и опыт для трудоустройства на позицию Junior Software Engineer (JavaScript / Front-end).

## Продолжительность

| Параметр | Значение |
|----------|----------|
| Срок | 5–7 месяцев |
| Нагрузка | 20–40 часов в неделю |

Программа обучения: [roadmap](https://github.com/rolling-scopes-school/tasks/blob/master/roadmap.md).

## Регистрация

Два варианта в зависимости от уровня подготовки.

### Подготовительный курс (Stage 0)

Для тех, кто мало знаком с программированием или только начинает.

| Тема | Описание |
|------|----------|
| HTML и CSS | Основы вёрстки |
| Git, GitHub | Основы работы с репозиторием |
| JavaScript | Базовый синтаксис |
| Алгоритмы | Сортировка и поиск |
| Структуры данных | Массив, список и др. |

- [Программа Stage 0](https://github.com/rolling-scopes-school/tasks/tree/master/stage0)
- [Регистрация на подготовительный курс](https://rs.school/courses/javascript-preschool-ru)

### Основной курс JavaScript / Front-end

**Требования перед стартом:**

- основы HTML и CSS, практические навыки вёрстки;
- основы JavaScript (типы, операторы, циклы, условия, функции);
- структуры данных (массив, список, стек, очередь, дерево и т.д.);
- простой алгоритм на JS (сортировка / поиск в массиве);
- задачи уровня 8–7 kyu на [Codewars](https://www.codewars.com/);
- желательно английский Pre-intermediate (минимум A2).

- [Программа основного курса](https://github.com/rolling-scopes-school/tasks/blob/master/roadmap.md)
- [Регистрация на курсы RS School](https://rs.school/courses)

## Этапы основного курса

| Этап | Что изучают | Формат |
|------|-------------|--------|
| [Stage 1](https://github.com/rolling-scopes-school/tasks/tree/master/stage1) | Git/GitHub, адаптивная вёрстка, Core JS, алгоритмы, DOM, Browser API, основы Node.js, проект Match-Match Game | Самообучение + вебинары + Discord; автопроверка и кросс-чек |
| [Stage 2](https://github.com/rolling-scopes-school/tasks/tree/master/stage2) | OOP, асинхронность, TypeScript, Node.js, презентация на английском, собеседование по Core JS | Менторинг; проверка ментором + кросс-чек; тренировочные интервью |
| [Stage 3](https://github.com/rolling-scopes-school/tasks/tree/master/stage3) | React или Angular, финальный командный проект, собеседование по фреймворку | Менторинг; проверка ментором + кросс-чек; тренировочные интервью |

Дополнительно: [EPAM JS LAB](https://github.com/rolling-scopes-school/tasks/blob/master/epam/epam-js-lab.md).
