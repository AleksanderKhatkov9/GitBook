# Собеседования

Основные вопросы на собеседовании на позицию **PHP Core + MySQL**, плюс отдельный блок по **Laravel**.

| Раздел | Описание |
|--------|----------|
| [PHP Core](php.md) | Типы, ООП, ошибки, массивы, безопасность, HTTP |
| [MySQL](mysql.md) | SQL, индексы, JOIN, транзакции, нормализация |
| [PHP/Laravel подготовка](php-laravel.md) | План подготовки по обратной связи Innovace: типы, ООП, SOLID, DI, SQL |
| [Laravel](laravel.md) | Container, Eloquent, middleware, очереди, auth, тесты |

## Как готовиться

1. Прочитайте вопросы и **ответьте вслух** своими словами.
2. Для спорных тем откройте связанные разделы книги и уточните детали.
3. Рядом держите практику: [Алгоритмы](../algorithm/README.md) + live coding на PHP.
4. По MySQL умейте писать JOIN / GROUP BY / подзапросы на доске или в редакторе.

## Что обычно проверяют

| Блок | Ожидание |
|------|----------|
| PHP Core | Типы, области видимости, ООП, `Throwable`, массивы, PDO |
| MySQL | SELECT с JOIN, индексы, транзакции, нормализация 1–3NF |
| Laravel | Container, Eloquent, N+1, middleware, очереди, Policies |
| Безопасность | SQL-инъекции, XSS, CSRF, хеш паролей, prepared statements |
| Практика | Разбор кода, SQL-задача, простой алгоритм на PHP |
