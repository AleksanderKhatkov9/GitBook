# 1. Начинающим

> [GrammarWay — Начинающим](https://grammarway.com/ru/) · [English File Pre-Intermediate](https://online.fliphtml5.com/aznks/ifwn/#p=1)

База перед грамматикой: алфавит, звуки и правила чтения.

## Английский алфавит

26 букв. Каждая буква имеет **название** (как произносится при перечислении) и может давать разные **звуки** в словах.

| Буква | Название | Буква | Название |
|-------|----------|-------|----------|
| A a | /eɪ/ | N n | /en/ |
| B b | /biː/ | O o | /əʊ/ |
| C c | /siː/ | P p | /piː/ |
| D d | /diː/ | Q q | /kjuː/ |
| E e | /iː/ | R r | /ɑː/ (BrE) |
| F f | /ef/ | S s | /es/ |
| G g | /dʒiː/ | T t | /tiː/ |
| H h | /eɪtʃ/ | U u | /juː/ |
| I i | /aɪ/ | V v | /viː/ |
| J j | /dʒeɪ/ | W w | /ˈdʌbljuː/ |
| K k | /keɪ/ | X x | /eks/ |
| L l | /el/ | Y y | /waɪ/ |
| M m | /em/ | Z z | /zed/ (BrE) /ziː/ (AmE) |

**Гласные:** A, E, I, O, U (иногда Y).  
**Согласные:** остальные.

## Фонетика — кратко

В английском **44 звука** (примерно). Письмо ≠ произношение — нужны транскрипция и слух.

### Важные пары

| Звук | Пример | Звук | Пример |
|------|--------|------|--------|
| /ɪ/ | sit | /iː/ | seat |
| /æ/ | cat | /ʌ/ | cut |
| /ɒ/ | hot (BrE) | /ɔː/ | door |
| /θ/ | think | /ð/ | this |
| /ʃ/ | she | /tʃ/ | chair |
| /ŋ/ | sing | /w/ | we |

### Ударение

В многосложных словах одно ударение обычно сильнее:

```
ˈtable   comˈputer   underˈstand
```

## Правила чтения (базовые)

### Гласные в открытом / закрытом слоге

| Тип слога | Пример | Звук (ориентир) |
|-----------|--------|-----------------|
| Открытый (…CV) | go, me, no | «алфавитный» |
| Закрытый (…CVC) | got, met, not | короткий |

### Сочетания

| Буквы | Часто читается | Пример |
|-------|----------------|--------|
| sh | /ʃ/ | ship |
| ch | /tʃ/ | chair |
| th | /θ/ или /ð/ | think / this |
| ph | /f/ | phone |
| ck | /k/ | back |
| ng | /ŋ/ | long |
| ee / ea | /iː/ | see / tea |
| oo | /uː/ или /ʊ/ | food / book |

### Немые буквы

| Буква | Пример |
|-------|--------|
| k перед n | know, knife |
| w перед r | write, wrong |
| b в конце после m | climb, comb |
| e на конце слова | make, time (удлиняет гласную) |

## Практические советы

1. Учите **звуки**, а не только буквы — слушайте English File.
2. Для каждого нового слова смотрите транскрипцию в словаре ([Cambridge](https://dictionary.cambridge.org/), [Oxford](https://www.oxfordlearnersdictionaries.com/)).
3. Читайте вслух короткие тексты 5–10 минут в день.
