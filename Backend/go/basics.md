# 2. Основы языка

> Источники: [Спецификация — Lexical elements, Types, Statements](https://go.dev/ref/spec) · [Metanit — глава 2](https://metanit.com/go/tutorial/)

## Структура файла

Каждый файл начинается с `package`. Затем — `import` и объявления.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    fmt.Println(math.Sqrt(9))
}
```

Неиспользуемый импорт и неиспользуемая локальная переменная — ошибка компиляции, а не предупреждение.

## Переменные

```go
var count int
count = 3

var title string = "заметки"

name := "Анна" // короткое объявление, только внутри функции
age := 20
age = 21
```

`:=` одновременно объявляет переменную и задаёт значение. Тип выводится справа. На уровне пакета `:=` нельзя — там только `var` и `const`.

Пока значение не задано, переменная хранит **нулевое значение** типа:

| Тип | Ноль |
|-----|------|
| Числа | `0` |
| `bool` | `false` |
| `string` | `""` |
| Указатель, срез, карта, канал, функция, интерфейс | `nil` |

## Типы

Числовые типы друг в друга **сами не превращаются**. `int` и `int32` — разные типы, даже если размер совпал.

```go
var a int32 = 10
var b int64 = int64(a)
```

| Группа | Типы |
|--------|------|
| Целые знаковые | `int8`, `int16`, `int32`, `int64`, `int` |
| Целые беззнаковые | `uint8`, `uint16`, `uint32`, `uint64`, `uint`, `uintptr` |
| Дробные | `float32`, `float64` |
| Комплексные | `complex64`, `complex128` |
| Прочие базовые | `bool`, `string`, `byte`, `rune` |

`byte` — другое имя `uint8`. `rune` — другое имя `int32`, один код Unicode. Размер `int` зависит от платформы (32 или 64 бита); для файла, сети и протокола берите тип с явной шириной.

## Константы

```go
const pi = 3.14159
const greeting = "ok"

const (
    Sunday = iota // 0
    Monday        // 1
    Tuesday       // 2
)
```

Константа без явного типа подстраивается под место использования. `iota` внутри блока `const` даёт 0, 1, 2, … — удобно для перечислений.

## Вывод

```go
fmt.Println("строка", 42)
fmt.Printf("имя=%s возраст=%d\n", name, age)
```

Частые глаголы `Printf`: `%d` целое, `%f` дробное, `%s` строка, `%t` bool, `%v` значение «как получится», `%T` тип, `%q` строка в кавычках.

## Операции

Арифметика: `+ - * / %`. Деление целых отбрасывает дробную часть: `5 / 2` равно `2`.

Сравнение: `== != < <= > >=`. Результат — `bool`. Строки сравниваются по байтам.

Логика: `&&`, `||`, `!`. `&&` и `||` не считают правую часть, если левой уже хватило.

Поразрядные: `&` и, `|` или, `^` исключающее или, `&^` сброс битов, `<<` `>>` сдвиги.

Присваивание: `= += -= *= /= %= &= |= ^= &^= <<= >>=`. `++` и `--` — отдельные инструкции, не выражения: `x = i++` не скомпилируется.

Приоритет привычный: унарные выше арифметики, арифметика выше сравнения, сравнение выше логики, присваивание — в конце. Скобки ставьте, когда выражение читается с усилием.

## Массивы

Длина — часть типа. `[3]int` и `[4]int` — разные типы, размер после создания не меняется.

```go
var nums [3]int
nums[0] = 10

letters := [3]string{"a", "b", "c"}
fmt.Println(len(letters), letters[1])
```

Для списка, который растёт, берут срез, не массив. Срезы — в главе [Структуры и коллекции](types.md).

## Условия

```go
if age >= 18 {
    fmt.Println("можно")
} else {
    fmt.Println("рано")
}
```

Короткая форма с объявлением. Переменные `n` и `err` видны только внутри `if` / `else`:

```go
if n, err := strconv.Atoi("42"); err != nil {
    fmt.Println(err)
} else {
    fmt.Println(n)
}
```

`switch` **не проваливается** в следующий `case`. Явный переход — ключевое слово `fallthrough`.

```go
switch n {
case 1, 2:
    fmt.Println("мало")
case 3:
    fmt.Println("три")
default:
    fmt.Println("много")
}

switch {
case n < 0:
    fmt.Println("минус")
case n == 0:
    fmt.Println("ноль")
}
```

## Циклы

Цикл в языке один — `for`.

```go
for i := 0; i < 3; i++ {
    fmt.Println(i)
}

for n > 0 {
    n--
}

for {
    break // бесконечный, пока сами не выйдем
}

for i, v := range letters {
    fmt.Println(i, v)
}
```

`break` выходит из цикла, `continue` переходит к следующей итерации. С Go 1.22 можно идти по целым: `for i := range 5` даёт 0, 1, 2, 3, 4.

`goto` в языке есть. В обычном коде он не нужен: те же развилки закрывают `if`, `switch` и `return`.

## Ключевые слова

Их нельзя брать как имена:

```text
break    default     func     interface  select
case     defer       go       map        struct
chan     else        goto     package    switch
const    fallthrough if       range      type
continue for         import   return     var
```
