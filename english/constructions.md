# 6. Обороты и конструкции

> [GrammarWay — Обороты](https://grammarway.com/ru/) · [English Grammar in Use](https://www.hasanboy.uz/wp-content/uploads/2017/11/English-grammar-in-Use.pdf)

## There is / There are

Указывает на **наличие** чего-либо (не «там» в смысле направления).

| Число | Present | Past |
|-------|---------|------|
| ед. | There is (There's) | There was |
| мн. | There are | There were |

```
There is a bug in the code.
There are three errors in the log.
Is there a problem? — Yes, there is. / No, there isn't.
There was a meeting yesterday.
There will be a release next week.
```

Согласование с **ближайшим** существительным при перечислении:

```
There is a keyboard and two mice on the desk.
There are two mice and a keyboard on the desk.
```

Не путать с *It is*:

```
There is a café nearby.     ← наличие
It is a good café.          ← характеристика
```

## To be going to

**Формула:** *am / is / are + going to + V*

| Значение | Пример |
|----------|--------|
| План / намерение | I'm going to refactor this module. |
| Прогноз по признакам | Look — it's going to crash. |

Сравнение с **will**:

| will | going to |
|------|----------|
| решение сейчас | план уже был |
| прогноз / мнение | очевидный исход |
| обещания, предложения | — |

```
— The deploy failed.
— I'll check the logs.              ← решение сейчас

I've booked a ticket. I'm going to fly on Monday.  ← план
```

Past: *was / were going to* — собирался, но…

```
I was going to call you, but my phone died.
```

## Used to

**Формула:** *used to + V* — привычка или состояние **в прошлом**, сейчас уже не так.

```
I used to write jQuery.     ← раньше писал, сейчас нет
She used to live in Minsk.
Did you use to work nights?
I didn't use to like coffee.
```

### Не путать

| Форма | Смысл | Пример |
|-------|-------|--------|
| **used to + V** | привычка в прошлом | I used to smoke. |
| **be used to + N / V-ing** | привычен к чему-то | I'm used to remote work. / I'm used to working late. |
| **get used to + N / V-ing** | привыкать | I'm getting used to the new IDE. |

```
I used to wake up at 5.           ← раньше вставал
I'm used to waking up at 5.       ← мне это привычно сейчас
I'm getting used to waking up at 5. ← постепенно привыкаю
```

## Другие полезные конструкции (кратко)

| Конструкция | Смысл | Пример |
|-------------|-------|--------|
| would rather | предпочёл бы | I'd rather stay. |
| would like to | хотел бы | I'd like to ask… |
| so / such | такой | so fast / such a fast PC |
| too / enough | слишком / достаточно | too slow / fast enough |
| either… or / neither… nor | или… или / ни… ни | either A or B |
