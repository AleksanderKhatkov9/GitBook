## Имена и объекты

Присваивание связывает **имя** с объектом. Объявлять тип заранее не нужно.

```python
count = 3
count = count + 1

title = "заметки"
title = 10  # то же имя, другой объект
```

Пока имени нет, обратиться к нему нельзя: будет `NameError`. «Нулевого значения по умолчанию» у несуществующего имени нет.

Одно значение можно повесить на несколько имён. Для изменяемых объектов это один и тот же объект:

```python
a = [1, 2]
b = a
b.append(3)
# a тоже [1, 2, 3]
```

## Типы

| Тип | Пример | Смысл |
|-----|--------|--------|
| `int` | `42`, `-7` | Целое любой длины |
| `float` | `3.14`, `1e-3` | Приближённое дробное, IEEE 754 |
| `complex` | `1+2j` | Комплексное |
| `bool` | `True`, `False` | Логическое; подкласс `int` |
| `str` | `"текст"` | Строка Unicode |
| `NoneType` | `None` | «Значения нет» |

`True + True` равно `2`, потому что `bool` наследует `int`. В условиях это редко нужно, в арифметике — легко ошибиться.

Проверка:

```python
type(count)          # <class 'int'>
isinstance(count, int)
count is None        # False
```

`None` сравнивают через `is` / `is not`: это один объект на весь процесс. `==` для своих классов можно переопределить, `is` смотрит на идентичность.

## Ввод и вывод

```python
name = input("Имя: ")
print("Привет,", name)
print("возраст", 20, sep=" = ", end="\n")
```

`input` всегда возвращает **строку**. Число из неё получают явно: `age = int(input("Возраст: "))`. Пустой ввод или текст вместо цифр даёт `ValueError`.

## Арифметика

`+ - * / // % **`

| Выражение | Результат | Почему |
|-----------|-----------|--------|
| `5 / 2` | `2.5` | `/` всегда даёт `float` |
| `5 // 2` | `2` | Целочисленное деление вниз |
| `5 % 2` | `1` | Остаток |
| `2 ** 10` | `1024` | Степень |
| `-5 // 2` | `-3` | Округление к минус бесконечности, не к нулю |

Скобки задают порядок. У `**` он выше, чем у унарного минуса: `-2 ** 2` равно `-4`, `(-2) ** 2` равно `4`.

## Сравнения и логика

`== != < <= > >=`. Сравнения можно сцеплять: `1 < x < 10` — это «x больше 1 и меньше 10», при этом `x` считается один раз.

`and`, `or`, `not` возвращают один из операндов, не обязательно `bool`:

```python
name = "" or "гость"   # "гость"
found = "a" and "b"    # "b"
```

`and` не считает правую часть, если левая уже ложная. `or` — если левая уже истинная.

Что считается ложью: `False`, `None`, ноль, пустая строка, пустой список, пустой словарь, пустое множество. Остальное — истина.

## Поразрядные операции

`&` и, `|` или, `^` исключающее или, `~` инверсия, `<<` `>>` сдвиги. Работают с целыми. Для флагов и масок, не для обычной арифметики.

## Условие

```python
if age < 18:
    print("рано")
elif age < 65:
    print("можно")
else:
    print("позже")
```

Ветки `elif` и `else` необязательны. Тело — строки с большим отступом. Одной строкой условие пишут редко: `status = "ok" if ready else "wait"`.

## Циклы

```python
n = 3
while n > 0:
    print(n)
    n -= 1

for i in range(3):
    print(i)  # 0, 1, 2
```

`range(stop)` — от 0 до `stop`, не включая конец. `range(1, 4)` — 1, 2, 3. `range(0, 10, 2)` — шаг 2.

`for` идёт по любому перебираемому объекту: строке, списку, словарю, файлу. Индекс нужен не всегда.

| Оператор | Что делает |
|----------|------------|
| `break` | Выход из ближайшего цикла |
| `continue` | Сразу к следующей итерации |
| `pass` | Пустая инструкция, когда тело ещё не написано |

У `for` и `while` бывает ветка `else`. Она выполняется, если цикл закончился сам, без `break`. Удобно для поиска: «прошли всё и не нашли».
