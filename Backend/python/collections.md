# 6. Коллекции

> Источники: [Учебник — структуры данных](https://docs.python.org/3/tutorial/datastructures.html) · [Справочник — отображения и последовательности](https://docs.python.org/3/reference/datamodel.html#emulating-container-types) · [Metanit — глава 5](https://metanit.com/python/tutorial/)

## Список

Список хранит объекты по порядку, длину можно менять.

```python
nums = [10, 20, 30]
nums.append(40)
nums[0] = 1
nums[-1]          # последний
nums[1:3]         # срез: индексы 1 и 2, конец не входит
```

| Операция | Смысл |
|----------|--------|
| `len(nums)` | Длина |
| `x in nums` | Есть ли значение |
| `nums.pop()` | Снять последний и вернуть его |
| `nums.insert(i, x)` | Вставить по индексу |
| `nums.remove(x)` | Удалить первое вхождение значения |
| `del nums[i]` | Удалить по индексу |
| `nums.sort()` | Сортировать на месте |

Срез возвращает **новый** список. Присваивание `b = a` нового списка не создаёт.

Список как стек: `append` кладёт, `pop` снимает с конца. Очередь на списке через `pop(0)` на каждом шаге сдвигает хвост. Для очереди берут `collections.deque`.

## Кортеж

Кортеж — упорядоченная неизменяемая последовательность.

```python
point = (1, 2)
x, y = point
single = (1,)   # запятая обязательна, (1) — это просто число
empty = ()
```

Сам кортеж нельзя пополнить. Если внутри лежит список, **этот список** менять можно: неизменяемость касается набора ссылок, а не вложенных объектов.

Кортеж используют, когда набор фиксирован: координата, пара «ключ — значение», то, что кладут в множество или используют ключом словаря.

## range

`range` — ленивая арифметическая прогрессия, не список. Память на миллион чисел не занимает, пока по ней не пройдут или не вызовут `list(range(...))`.

```python
for i in range(5):
    print(i)
```

Конец не входит в диапазон.

## Словарь

Словарь сопоставляет **хешируемый** ключ значению. С Python 3.7 порядок вставки сохраняется.

```python
user = {"name": "Анна", "age": 20}
user["city"] = "Минск"
user["name"]
user.get("phone")        # None, если ключа нет
user.get("phone", "—")   # своё значение по умолчанию
```

`user["phone"]` при отсутствии ключа — `KeyError`. `get` в этом случае исключение не бросает.

| Операция | Смысл |
|----------|--------|
| `del user["age"]` | Удалить ключ |
| `"name" in user` | Есть ли ключ (не значение) |
| `user.keys()` | Ключи |
| `user.values()` | Значения |
| `user.items()` | Пары для цикла |

```python
for key, value in user.items():
    print(key, value)
```

Ключ должен быть неизменяемым в смысле хеша: число, строка, кортеж из таких же объектов. Список ключом быть не может.

## Множество

Множество хранит уникальные хешируемые объекты. Порядок не обещан.

```python
ids = {1, 2, 2, 3}   # {1, 2, 3}
ids.add(4)
empty = set()        # {} — это пустой словарь, не множество
```

`|` объединение, `&` пересечение, `-` разность. Проверка `x in ids` в среднем быстрее, чем по длинному списку.

## Включения

Включение строит коллекцию из цикла в одном выражении.

```python
squares = [n * n for n in range(5)]
even = [n for n in range(10) if n % 2 == 0]
names = {user["name"] for user in [{"name": "Анна"}, {"name": "Борис"}]}
ages = {name: len(name) for name in ["Анна", "Борис"]}
```

Скобки решают тип: `[]` список, `{}` со словарём или множеством (множество — если нет двоеточия), `()` здесь будет не кортеж, а генератор.

## Распаковка

```python
first, *rest = [1, 2, 3, 4]   # first == 1, rest == [2, 3, 4]
a, b = b, a                    # обмен без временной переменной

def move(x, y):
    print(x, y)

point = (3, 4)
move(*point)

options = {"sep": " | ", "end": "\n"}
print("a", "b", **options)
```

`*` разворачивает последовательность в позиционные аргументы, `**` — словарь в именованные.

`zip` склеивает несколько последовательностей в пары и останавливается на самой короткой:

```python
names = ["Анна", "Борис"]
scores = [10, 8]
for name, score in zip(names, scores):
    print(name, score)
```
