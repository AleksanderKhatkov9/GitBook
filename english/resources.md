## План на 8 недель (A2 → B1)

| Неделя | Фокус в GitBook | Практика |
|--------|-----------------|----------|
| 1 | [Начинающим](beginners.md) + артикли | English File: Unit 1–2 |
| 2 | Present Simple / Continuous | Murphy: Present; File: Present |
| 3 | Past Simple / Continuous | Murphy: Past; неправильные глаголы |
| 4 | Present Perfect | Murphy: Present Perfect vs Past |
| 5 | [Модальные](modals.md) + [Обороты](constructions.md) | can/must/should, going to, used to |
| 6 | Степени сравнения, предлоги | File + Murphy: comparatives |
| 7 | [Условные](sentence.md) 0–2 | if / when / unless |
| 8 | Косвенная речь + Passive | short dialogues, tags |

Каждый день: **15–20 мин правила** + **15–20 мин упражнения** + **5 мин вслух**.

## Чеклист тем

### Начинающим
- [ ] Алфавит и названия букв
- [ ] Базовые звуки /θ/ /ð/ /ŋ/ /æ/
- [ ] Правила чтения sh, ch, th, немое e

### Части речи
- [ ] a / an / the / нулевой артикль
- [ ] Countable / uncountable
- [ ] Личные и притяжательные местоимения
- [ ] Предлоги in / on / at (время и место)

### Глаголы и времена
- [ ] to be (am/is/are, was/were)
- [ ] Present Simple vs Continuous
- [ ] Past Simple (+ неправильные)
- [ ] Present Perfect (ever/never/just/already/yet/for/since)
- [ ] will vs going to
- [ ] Passive (Present / Past)

### Модальные и конструкции
- [ ] can / could / must / have to / should
- [ ] there is / there are
- [ ] used to vs be used to

### Предложение
- [ ] Порядок слов SVO
- [ ] Yes/No и Wh-вопросы
- [ ] Conditionals 0, 1, 2
- [ ] Reported speech (базовый сдвиг)

## Как работать с тремя источниками

```
1. Тема в GitBook (этот раздел)     ← структура и шпаргалка
2. Та же тема на GrammarWay         ← развёрнутые примеры
3. Упражнения в English Grammar in Use
4. Диалог / текст в English File    ← живой контекст
5. Закрепление в ChatGPT            ← см. ИИ: грамматика и речь
```

Не копируйте юниты подряд без цели: берите **одну тему**, доведите до уверенных упражнений, затем следующую.
