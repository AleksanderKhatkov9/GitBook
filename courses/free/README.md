## С чего начать

1. **Новичок в программировании** → [RS School Stage 0](rs-school.md), [freeCodeCamp / Odin](practice.md) или бесплатный курс на [Stepik](stepik.md).
2. **Есть база HTML/CSS/JS** → основной курс [RS School](rs-school.md); параллельно [Codewars](codewars.md) (8–7 kyu).
3. **Алгоритмы и собеседования** → [Codewars](codewars.md) → [LeetCode](leetcode.md); план в [Algorithm](../../algorithm/README.md).
4. **Узкая тема** (SQL, Python, Linux) → [Stepik](stepik.md) с фильтром «Бесплатные».

См. также: [Платные курсы](../paid/README.md).
