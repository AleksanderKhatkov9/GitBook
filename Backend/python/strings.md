# 8. Строки

> Источники: [Учебник — текст](https://docs.python.org/3/tutorial/introduction.html#text) · [Методы str](https://docs.python.org/3/library/stdtypes.html#string-methods) · [Metanit — глава 7](https://metanit.com/python/tutorial/)

## Строка — последовательность символов

Строка в Python 3 — последовательность символов Unicode, не байтов. Байты — отдельный тип `bytes`.

```python
name = "Анна"
also = 'Анна'
long = """строка
на две линии"""
```

Кавычки `"` и `'` равноправны. Тройные кавычки держат перевод строки внутри литерала.

Строка **неизменяема**. `name.upper()` возвращает новую строку, старую не переписывает. «Изменить символ по индексу» нельзя: собирают новую строку.

## Индексы и срезы

Индексация с нуля. Отрицательный индекс считает с конца: `-1` — последний символ.

```python
word = "python"
word[0]     # "p"
word[-1]    # "n"
word[1:4]   # "yth" — конец не входит
word[:2]    # "py"
word[::2]   # "pto" — шаг 2
len(word)   # 6
```

Срез за границей ошибку не даёт, одиночный индекс за границей — `IndexError`.

По строке идут циклом, как по последовательности:

```python
for ch in word:
    print(ch)
```

`len` считает символы Unicode, не байты. «й» — один символ, хотя в UTF-8 занимает два байта.

## Методы

Метод не меняет исходную строку.

| Метод | Результат |
|-------|-----------|
| `s.lower()` / `s.upper()` | Регистр |
| `s.strip()` | Убрать пробелы по краям |
| `s.replace("a", "b")` | Заменить непересекающиеся вхождения |
| `s.split(",")` | Список частей |
| `",".join(parts)` | Склеить строки через разделитель |
| `s.startswith("py")` | Проверка префикса |
| `s.find("th")` | Индекс или `-1` |
| `"42".isdigit()` | Все ли символы — цифры |

```python
parts = "Анна,Борис".split(",")
", ".join(parts)   # "Анна, Борис"
```

`join` вызывают у разделителя, не у списка. В список должны лежать строки; числа сначала превращают в `str`.

## Форматирование

Основной способ — **f-строка**. Выражения в `{}` считаются в момент создания строки.

```python
name = "Анна"
age = 20
text = f"{name} — {age} лет"
text = f"{name!r}"       # как repr, в кавычках
text = f"{age:03d}"      # 020
text = f"{3.14159:.2f}"  # 3.14
```

Тот же смысл у метода `format` и у оператора `%`. Их встречают в старом коде:

```python
"{} — {} лет".format(name, age)
"%s — %d лет" % (name, age)
```

В новом коде достаточно f-строк. В f-строку нельзя подставить значение, которое пришло от пользователя, и тут же выполнить его как код: подстановка вставляет текст, не запускает его. Опасен `eval` от чужого ввода, а не кавычки в f-строке.

Конкатенация в цикле через `+` на каждой итерации копирует растущую строку. Много кусков собирают списком и одним `join`.

## Строка и байты

```python
raw = "Привет".encode("utf-8")   # bytes
raw.decode("utf-8")              # обратно str
```

Файл, сокет и HTTP отдают байты. Пока вы не назвали кодировку, это ещё не текст. Для обычных исходников и `open(..., encoding="utf-8")` кодировка — UTF-8.
