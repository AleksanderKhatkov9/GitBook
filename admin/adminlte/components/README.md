# Компоненты

> Официальная документация: [Components | AdminLTE 4](https://adminlte.io/themes/v4/docs/components/main-header.html)

AdminLTE предоставляет **application shell**; UI-компоненты (кнопки, формы, таблицы, модалки) — из **Bootstrap 5**.

## Разделы

| Страница | Описание |
|----------|----------|
| [Header](header.md) | Navbar, уведомления, профиль |
| [Sidebar](sidebar.md) | Бренд, меню, treeview |
| [Карточки и виджеты](cards-widgets.md) | Cards, info-box, small-box |

## AdminLTE vs Bootstrap

| Слой | Ответственность |
|------|-----------------|
| AdminLTE | `app-wrapper`, header, sidebar, footer, виджеты админки |
| Bootstrap 5 | Кнопки, формы, таблицы, alerts, modals, dropdowns |
| Bootstrap Icons | Иконки в меню и toolbar |

## Демо-страницы

Готовые примеры в [live preview](https://adminlte.io/themes/v4):

- Dashboard v2/v3
