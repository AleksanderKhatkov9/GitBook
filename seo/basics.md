# 1. Основы SEO

> Источники: [Google — How Search Works](https://developers.google.com/search/docs/fundamentals/how-search-works) · [MDN — SEO](https://developer.mozilla.org/ru/docs/Glossary/SEO)

## Как работает поиск

1. **Краулинг** — робот (Googlebot) обходит ссылки и скачивает страницы.
2. **Индексация** — страница попадает в базу поисковика.
3. **Ранжирование** — по запросу выбираются и сортируются релевантные страницы.

```
Пользователь → запрос в Google → SERP (выдача) → клик → ваш сайт
```

## SERP — страница результатов

| Элемент | Что влияет |
|---------|------------|
| Title (синяя ссылка) | Тег `<title>`, иногда переопределяется Google |
| Snippet (описание) | `<meta name="description">`, текст со страницы |
| URL | Читаемый путь, HTTPS |
| Rich results | Schema.org, FAQ, рейтинги |

## Типы SEO

### On-Page

Оптимизация **содержимого и разметки** страницы: заголовки, текст, ключевые слова, meta-теги.

### Technical

**Инфраструктура:** скорость загрузки, мобильная версия, индексация, дубли, редиректы, SSL.

### Off-Page

**Авторитет домена:** backlinks, упоминания, соцсигналы. Не контролируется напрямую с сайта.

## KPI — метрики

| Метрика | Описание |
|---------|----------|
| Organic traffic | Визиты из поиска |
| Impressions | Показы в выдаче |
| CTR | Клики / показы × 100% |
| Average position | Средняя позиция по запросам |
| Bounce rate | Ушли без действий (аналитика) |
| Core Web Vitals | LCP, INP, CLS — скорость и UX |

## E-E-A-T (Google)

| Буква | Значение |
|-------|----------|
| Experience | Опыт автора в теме |
| Expertise | Экспертность |
| Authoritativeness | Авторитет сайта/автора |
| Trustworthiness | Доверие: контакты, политика, HTTPS |

Важно для YMYL-тем (медицина, финансы, юриспруденция).

## Белое vs чёрное SEO

| Подход | Описание |
|--------|----------|
| White hat | Качественный контент, техническая оптимизация |
| Black hat | Спам, скрытый текст, покупные ссылки — риск бана |

## Поисковые системы

| Система | Доля (ориентир) | Инструмент |
|---------|-----------------|------------|
| Google | ~90% (глобально) | Search Console |
| Yandex | ~60% (РФ/СНГ) | Яндекс Вебмастер |
| Bing | ~3–5% | Bing Webmaster |
