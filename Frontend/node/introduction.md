# 1. Введение в Node.js

> Источники: [Metanit — глава 1](https://metanit.com/web/nodejs/) · [About this documentation](https://nodejs.org/docs/latest/api/documentation.html) · [nodejs.org](https://nodejs.org/)

Node.js — среда выполнения JavaScript на движке V8. Программа запускается из терминала, а не из тега `<script>`. Отдельного языка «Node» нет: это тот же JavaScript плюс встроенные модули для файлов, сети и процесса.

## Браузер и Node.js

| | Браузер | Node.js |
|--|---------|---------|
| Где работает | Вкладка | Процесс ОС |
| Страница | DOM, `window`, `document` | Нет DOM |
| Сеть | `fetch` из страницы | Свой HTTP-сервер и `fetch` |
| Файлы | Нет доступа к диску | `node:fs` |
| Модули | `<script type="module">` | CommonJS и ES-модули |
| Типичная задача | Интерфейс | API, CLI, SSR, сборка |

Сборщики (Vite) и [Next.js](../js/next/README.md) — тоже процессы Node.js. Запуск Next.js на сервере: [PM2](../pm2/README.md).

Нужны основы [JavaScript](../js/README.md): переменные, функции, объекты, Promise. Без этого сначала глава [Введение в JavaScript](../js/introduction/introduction.md).

## Цикл событий

JavaScript в одном процессе Node.js выполняется в одном потоке. Пока идёт ваш код, второй запрос не начнёт выполняться.

Долгие операции ввода-вывода (файл, сокет, DNS) уходят в libuv. Когда они готовы, колбэк или Promise возвращается в очередь, и цикл событий его вызывает. Поэтому сервер может держать много соединений, не создавая поток на каждый запрос.

Следствие: `readFileSync` и тяжёлый цикл `while` останавливают обработку всех запросов. Для файлов и сети берите асинхронные функции. Тяжёлый CPU-расчёт выносят в [worker threads](https://nodejs.org/docs/latest/api/worker_threads.html) или в отдельный процесс — на сервере это часто делает [PM2 в режиме cluster](../pm2/README.md).

## Версии

| Ветка | Как выбирать |
|-------|----------------|
| 24.x LTS | Обычный выбор для нового проекта |
| 22.x LTS | Ещё поддерживается, если хостинг или CI уже на 22 |
| 26.x Current | Новые API раньше, чем в LTS |

Чётные мажорные версии становятся LTS. В справочнике смотрите индекс стабильности: экспериментальный модуль на Current может потребовать флаг и не попасть в следующий LTS без изменений. Шкала индексов — в [обзоре раздела](README.md).

## Установка

Установщик LTS: [nodejs.org](https://nodejs.org/). Проверка в PowerShell или bash:

```bash
node -v
npm -v
```

Несколько версий на одной машине ставят через менеджер версий (nvm, nvm-windows, fnm), а не поверх друг друга из разных установщиков.

## Первое приложение

Файл `app.js`:

```js
console.log('Привет, Node.js');
console.log(process.version);
```

Запуск из каталога с файлом:

```bash
node app.js
```

`console.log` пишет в stdout. `process.version` — версия Node.js, в браузере такого объекта нет.

Код завершается, когда не осталось работы: ни текущего вызова, ни ожидающих таймеров, ни открытых серверов. Скрипт выше печатает две строки и сразу выходит.

## REPL

Интерактивная консоль:

```bash
node
```

```text
> 2 + 2
4
> .exit
```

Удобно проверить выражение. Приложение всё равно пишут в файл и запускают через `node app.js`.
