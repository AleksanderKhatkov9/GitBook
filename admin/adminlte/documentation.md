## Что такое AdminLTE

**AdminLTE** — бесплатный MIT-шаблон админ-панели на Bootstrap 5.3.8 с vanilla TypeScript. Включает:

- адаптивные макеты;
- боковое меню с treeview;
- light / dark / auto color mode;
- RTL-поддержку;
- демо-страницы: calendar, kanban, chat, invoice, profile и др.

AdminLTE — это **application shell** (каркас приложения). Компоненты UI даёт Bootstrap 5; AdminLTE добавляет оболочку админки.
