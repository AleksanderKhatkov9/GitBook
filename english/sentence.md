# 8. Предложение

> [GrammarWay — Предложение](https://grammarway.com/ru/) · [English Grammar in Use](https://www.hasanboy.uz/wp-content/uploads/2017/11/English-grammar-in-Use.pdf) · [English File](https://online.fliphtml5.com/aznks/ifwn/#p=1)

## Порядок слов (Word Order)

Базовый порядок в утверждениях:

```
Subject + Verb + Object + Manner + Place + Time
   I    +  wrote +  code + quickly + at home + yesterday
```

| Член | Примеры |
|------|---------|
| Subject (подлежащее) | I, the team, bugs |
| Predicate (сказуемое) | work, is fixing, has deployed |
| Object (дополнение) | a bug, the API |
| Adverbials | carefully, in Minsk, on Monday |

Обстоятельства частоты — перед смысловым глаголом / после *be*:

```
I often deploy on Fridays.
She is never late.
```

---

## Главные и второстепенные члены

| Член | Роль | Пример |
|------|------|--------|
| Subject | кто / что делает | **The server** crashed. |
| Predicate | действие / состояние | The server **crashed**. |
| Object | на что направлено | She fixed **the bug**. |
| Attribute | определение | a **critical** bug |
| Adverbial | обстоятельство | He works **remotely**. |

## Типы предложений

| Тип | Пример |
|-----|--------|
| Простое | I write code. |
| Сложносочинённое | I write code, and she writes tests. |
| Сложноподчинённое | I write code because I like it. |

Союзы: *and, but, or, so, because, if, when, although, that, which…*

## Типы вопросов

### 1. Yes / No (общий)

Вспомогательный глагол + подлежащее + V:

```
Do you use Git?
Is she a developer?
Have you finished?
Can you help?
```

### 2. Wh- (специальный)

Wh-слово + вспомогательный + подлежащее + V:

```
What do you do?
Where does he work?
When did you deploy?
Why are you late?
How long have you lived here?
Who wrote this?          ← who = подлежащее → без do
```

### 3. Alternative (альтернативный)

```
Do you prefer Vue or React?
```

### 4. Tag questions (разделительный)

```
You use Linux, don't you?
She isn't ready, is she?
```

## Условные предложения (Conditionals)

| Тип | If-clause | Main clause | Смысл |
|-----|-----------|-------------|-------|
| **Zero** | Present | Present | всегда верно |
| **1st** | Present | will + V | реальное будущее |
| **2nd** | Past Simple | would + V | гипотеза сейчас |
| **3rd** | Past Perfect | would have + V3 | нереальное прошлое |
| **Mixed** | Past Perfect | would + V | прошлое → сейчас |

```
Zero:  If you heat water, it boils.
1st:   If it rains, I'll stay home.
2nd:   If I had more time, I would learn Rust.
       If I were you, I'd refactor this.
3rd:   If I had tested it, the bug wouldn't have shipped.
Mixed: If I had slept more, I wouldn't be tired now.
```

*Unless* = *if not*: *Unless you save, you'll lose data.*

## Косвенная речь (Reported Speech)

### Сдвиг времён (после said / told)

| Прямая | Косвенная |
|--------|-----------|
| Present Simple | Past Simple |
| Present Continuous | Past Continuous |
| Present Perfect | Past Perfect |
| Past Simple | Past Perfect |
| will | would |
| can | could |
| may | might |
| must / have to | had to |

```
"I am busy." → She said (that) she was busy.
"I will call." → He said he would call.
"I have finished." → She said she had finished.
```

### Указатели времени / места

| Прямая | Косвенная |
|--------|-----------|
| now | then |
| today | that day |
| yesterday | the day before |
| tomorrow | the next day |
| here | there |
| this | that |

### Вопросы и просьбы

```
"Where do you work?" → He asked where I worked.
"Do you like PHP?" → She asked if / whether I liked PHP.
"Open the file." → He told me to open the file.
"Don't touch it." → She told me not to touch it.
```

*say* + (that); *tell* + **кому** + (that): *She told **me** that…*

## Простые vs сложные — практика

```
Простое:     The build failed.
Сложное:     The build failed because the tests timed out.
С придаточным: The build that we started at noon failed.
Условное:    If the tests fail, we won't deploy.
Косвенная:   He said the tests had failed.
```
