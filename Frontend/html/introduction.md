# 1. Введение в HTML5

> Источники: [metanit.com — Введение в HTML5](https://metanit.com/web/html5/1.1.php) · [W3Schools — HTML Introduction](https://www.w3schools.com/html/html_intro.asp) · [htmlbook.ru — Самоучитель HTML5](https://htmlbook.ru/samhtml5)

HTML — стандартный язык разметки для веб-страниц. Браузер читает HTML-документ, строит DOM-дерево и отображает содержимое.

## Что такое HTML

HTML описывает **содержимое** страницы с помощью **элементов** (тегов). Каждый элемент может иметь **атрибуты** и вложенное содержимое.

```html
<p class="intro" id="welcome">Текст абзаца</p>
```

| Часть | Пример | Описание |
|-------|--------|----------|
| Открывающий тег | `<p>` | Начало элемента |
| Атрибуты | `class="intro"` | Дополнительные параметры |
| Содержимое | `Текст абзаца` | Текст или другие элементы |
| Закрывающий тег | `</p>` | Конец элемента |

### Пустые (void) элементы

Некоторые элементы не имеют закрывающего тега и содержимого:

```html
<meta charset="UTF-8">
<img src="photo.jpg" alt="Фото">
<br>
<input type="text">
<hr>
```

## Элементы и атрибуты

### Глобальные атрибуты

Применяются к большинству элементов:

| Атрибут | Назначение |
|---------|------------|
| `id` | Уникальный идентификатор на странице |
| `class` | Класс для CSS и JavaScript |
| `style` | Инлайн-стили (лучше избегать) |
| `title` | Всплывающая подсказка |
| `hidden` | Скрывает элемент |
| `lang` | Язык содержимого |
| `data-*` | Пользовательские данные |

```html
<div id="app" class="container" data-user-id="42">
    Контент
</div>
```

### Булевы атрибуты

Если атрибут присутствует — он истинен, значение можно не указывать:

```html
<input type="checkbox" checked>
<button disabled>Отправить</button>
<details open>
    <summary>Подробнее</summary>
    <p>Развёрнутый текст</p>
</details>
```

## Создание документа

### DOCTYPE и корневая структура

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <!-- Метаданные — не отображаются на странице -->
</head>
<body>
    <!-- Видимое содержимое -->
</body>
</html>
```

- `<!DOCTYPE html>` — объявление HTML5; сообщает браузеру режим стандартов.
- `<html lang="ru">` — корневой элемент; `lang` важен для SEO и скринридеров.
- `<head>` — метаданные, заголовок, подключение CSS/JS.
- `<body>` — всё, что видит пользователь.

### Элемент head

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Краткое описание страницы">
    <title>Заголовок вкладки браузера</title>
    <link rel="icon" href="/favicon.ico">
    <link rel="stylesheet" href="/css/style.css">
    <script src="/js/app.js" defer></script>
</head>
```

| Элемент | Назначение |
|---------|------------|
| `<meta charset>` | Кодировка (UTF-8 — стандарт) |
| `<meta name="viewport">` | Адаптивность на мобильных |
| `<title>` | Заголовок страницы (вкладка, закладки, SEO) |
| `<link>` | Подключение CSS, иконок, шрифтов |
| `<script>` | Подключение JavaScript |

### Комментарии

```html
<!-- Это комментарий. Браузер его не отображает. -->
```

## Разновидности синтаксиса

### HTML5 (рекомендуется)

Современный стандарт. Регистр тегов не важен, но принято писать **строчными** буквами:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Страница</title>
</head>
<body>
    <img src="logo.png" alt="Логотип">
</body>
</html>
```

### XHTML (устаревший)

Строгий XML-подобный синтаксис: все теги в нижнем регистре, обязательное закрытие, кавычки у атрибутов:

```html
<img src="logo.png" alt="Логотип" />
<br />
```

В новых проектах используйте HTML5.

## Блочные и строчные элементы

| Тип | Поведение | Примеры |
|-----|-----------|---------|
| Блочные | Занимают всю ширину, начинаются с новой строки | `div`, `p`, `h1`–`h6`, `ul`, `section` |
| Строчные | Идут в одной строке, ширина по содержимому | `span`, `a`, `strong`, `em`, `img` |

```html
<p>Абзац — <strong>блочный</strong> элемент.</p>
<p>Строчный <a href="#">элемент</a> внутри абзаца.</p>
```

## Группировка элементов

```html
<div>Универсальный блочный контейнер без семантики</div>
<span>Универсальный строчный контейнер без семантики</span>
```

Для структуры страницы предпочитайте **семантические** элементы — см. [главу 4](semantics.md).

## Проверка разметки

Валидатор W3C находит ошибки в структуре документа:

- [validator.w3.org](https://validator.w3.org/)

Типичные ошибки:

- Пропущен `<!DOCTYPE html>`
- Не указан `lang` у `<html>`
- У `<img>` нет атрибута `alt`
- Вложенность нарушена (например, `<p>` внутри `<p>`)
