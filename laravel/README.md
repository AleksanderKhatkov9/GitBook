# Laravel 13.x

> Официальная документация: [laravel.com/docs/13.x](https://laravel.com/docs/13.x)

Laravel — веб-фреймворк на PHP с выразительным синтаксисом. Он даёт структуру приложения, dependency injection, работу с БД, очереди, тесты и многое другое.

## Быстрый старт

```bash
laravel new my-app
cd my-app
composer run dev
```

Приложение: [http://localhost:8000](http://localhost:8000)
