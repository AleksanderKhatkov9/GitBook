# Go

**Go** — компилируемый язык для серверов, утилит и инфраструктуры. Строгая типизация, сборка мусора и встроенная параллельность (горутины и каналы). Программа собирается из пакетов, зависимости описывает модуль `go.mod`.

> [Спецификация языка](https://go.dev/ref/spec) (go1.27) · [Metanit — руководство по Go](https://metanit.com/go/tutorial/) · [A Tour of Go](https://go.dev/tour/) · [Effective Go](https://go.dev/doc/effective_go)

Этот раздел — сжатый справочник по главам Metanit. Формулировки свои, источник истины по синтаксису — спецификация. Примеры короткие: их нужно читать и запускать, а не копировать пакетом.

## Чем Go удобен на бэкенде

| Свойство | На практике |
|----------|-------------|
| Один бинарник | Собрали на CI — скопировали на сервер, рантайм отдельно не ставят |
| Быстрая сборка | Короткий цикл «поменял — проверил» |
| Горутины | Тысячи одновременных задач без ручного пула потоков |
| Стандартная библиотека | HTTP, JSON, криптография, тесты — без фреймворка на старте |
| `gofmt` | Один стиль на весь код, спорить о скобках не о чем |
