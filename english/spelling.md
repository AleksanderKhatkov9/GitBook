## Заглавные буквы (Capital letters)

Пишутся с большой буквы:

| Случай | Пример |
|--------|--------|
| Начало предложения | The server is down. |
| Имена, фамилии | Alice Johnson |
| Дни, месяцы, праздники | Monday, July, Christmas |
| Национальности, языки | English, Belarusian |
| Названия компаний, продуктов | Google, Laravel, GitHub |
| Заголовки (Title Case — часто) | Getting Started with Git |
| Местоимение **I** | I think… |
| География | Minsk, the Atlantic Ocean |

**Не** пишут с большой (обычно): времена года (*summer*), обычные должности без имени (*a developer*).

## Даты и время

### Даты

| Формат | Пример | Регион |
|--------|--------|--------|
| 28 July 2026 / 28th July 2026 | день + месяц | BrE |
| July 28, 2026 | месяц + день | AmE |
| 28/07/2026 | ДД/ММ/ГГГГ | BrE |
| 07/28/2026 | ММ/ДД/ГГГГ | AmE — путаница! |

В технике безопаснее: **ISO 8601** — `2026-07-28`.

Предлоги: *on Monday*, *in July*, *in 2026*, *at 5 p.m.*

### Время

```
5 o'clock / 5:00
half past five / 5:30
a quarter past five / 5:15
a quarter to six / 5:45
am / pm  или  24-hour: 17:30
```

## Пунктуация

### Точка (Full stop / Period) `.`

Конец повествовательного предложения. Сокращения: *Mr.*, *e.g.*, *etc.* (в BrE часто без точки у *Mr Mrs Dr*).

### Запятая (Comma) `,`

| Случай | Пример |
|--------|--------|
| Перечисление | red, green, and blue |
| Вводные слова | However, we need tests. |
| Обращение | Alex, can you help? |
| Однородные придаточные | If it fails, we roll back. |
| Non-defining relative | My laptop, which is new, is fast. |

**Oxford comma** (перед *and* в списке) — часто в AmE: *A, B, and C*.

### Вопросительный / восклицательный `?` `!`

```
Are you ready?
Watch out!
```

### Апостроф `'`

| Случай | Пример |
|--------|--------|
| Притяжательный | the developer's laptop |
| Сокращения | don't, I'm, it's (= it is / it has) |

**its** (притяжательное) ≠ **it's** (it is):

```
The project has its own repo.
It's ready.   ← It is ready.
```

### Кавычки

| Стиль | Пример |
|-------|--------|
| AmE | "Hello," she said. |
| BrE | 'Hello,' she said. / “Hello” |

Код и термины в документации часто в `` `backticks` ``.

### Двоеточие / точка с запятой

```
We need three things: tests, docs, and CI.
I fixed the API; she updated the UI.
```

### Дефис / тире

| Знак | Пример |
|------|--------|
| hyphen `-` | well-known, twenty-one |
| en/em dash `–` `—` | The fix — finally — worked. |

## Частые ошибки в письме

| Ошибка | Верно |
|--------|-------|
| Your welcome | You're welcome |
| Its ready | It's ready |
| I am agree | I agree |
| informations | information |
| advices | advice (uncountable) |
| He don't | He doesn't |
