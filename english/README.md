## Рекомендуемый порядок

```
Начинающим → Части речи → Глагол to be
    → Present Simple / Continuous
    → Past Simple → Present Perfect
    → Модальные → Условные → Косвенная речь
```

Параллельно: лексика и диалоги из **English File**, упражнения из **English Grammar in Use**.

## Быстрая шпаргалка: времена

| Время | Формула | Пример |
|-------|---------|--------|
| Present Simple | V / V-s | I work / He works |
| Present Continuous | am/is/are + V-ing | She is working |
| Past Simple | V2 / V-ed | I worked / I went |
| Past Continuous | was/were + V-ing | I was working |
| Present Perfect | have/has + V3 | I have worked |
| Future Simple | will + V | I will work |
| be going to | am/is/are + going to + V | I am going to work |

Полная таблица — в [Временах](tenses.md).
