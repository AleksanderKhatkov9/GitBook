# Layout (плагин)

> Официальная документация: [Layout | AdminLTE 4](https://adminlte.io/themes/v4/docs/javascript/layout.html)

Плагин Layout управляет классами на `<body>` и синхронизирует состояние макета (fixed, sidebar collapse, responsive).

## Что делает

- применяет классы раскладки при загрузке;
- реагирует на resize окна;
- координирует работу с PushMenu.

## Классы body

Задаются в HTML или переключаются через Layout/PushMenu:

```html
<body class="layout-fixed sidebar-expand-lg">
```

См. полный список — [Классы раскладки](../layout-classes.md).
