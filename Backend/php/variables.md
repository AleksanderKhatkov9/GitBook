# Переменные

> Источник: [Переменные | PHP Manual](https://www.php.net/manual/ru/language.variables.php)

## Основы

Переменные начинаются с `$`, имя чувствительно к регистру:

```php
<?php

$name = 'PHP';
$Name = 'другое'; // другая переменная
```

Имя: буква или `_`, затем буквы, цифры, `_`.

Присваивание по значению (копия для скаляров) и по ссылке:

```php
<?php

$a = 1;
$b = $a;   // копия
$c = &$a;  // ссылка на $a
$a = 2;    // $c тоже станет 2
```

## Область видимости

| Область | Описание |
|---------|----------|
| Локальная | Внутри функции / метода |
| Глобальная | Вне функций |
| Статическая | Сохраняет значение между вызовами функции |
| Суперглобальная | Доступна везде (`$_GET`, `$_POST`, …) |

```php
<?php

$global = 'снаружи';

function demo(): void
{
    global $global; // доступ к глобальной
    echo $global;

    static $count = 0;
    $count++;
    echo $count;
}
```

Внутри функции локальные переменные не видят глобальные без `global` или `$GLOBALS`.

## Переменные переменные

```php
<?php

$foo = 'bar';
$$foo = 'baz'; // создаёт $bar = 'baz'
echo $bar;     // baz
```

Используйте осторожно — снижает читаемость.

## Суперглобальные переменные

> Источник: [Предопределённые переменные](https://www.php.net/manual/ru/reserved.variables.php)

| Переменная | Назначение |
|------------|------------|
| `$GLOBALS` | Все глобальные переменные |
| `$_SERVER` | Сервер и окружение |
| `$_GET` | Query string |
| `$_POST` | Тело POST (form-urlencoded / multipart) |
| `$_FILES` | Загруженные файлы |
| `$_COOKIE` | Cookies |
| `$_SESSION` | Данные сессии |
| `$_REQUEST` | Объединение GET/POST/COOKIE (не рекомендуется) |
| `$_ENV` | Переменные окружения |

```php
<?php

$id = $_GET['id'] ?? null;
$email = $_POST['email'] ?? '';
$ua = $_SERVER['HTTP_USER_AGENT'] ?? '';
```

Никогда не доверяйте пользовательскому вводу без проверки и экранирования. См. [Безопасность](security.md).

## Переменные извне

Данные приходят через HTTP (GET/POST), cookies, окружение, CLI (`$argv`, `$argc`). В фреймворках предпочтительнее Request-объекты, а не прямой доступ к суперглобальным.

Далее: [Константы](constants.md).
