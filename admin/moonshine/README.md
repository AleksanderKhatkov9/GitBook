# Moonshine

> Официальная документация: [moonshine-laravel.com/docs](https://moonshine-laravel.com/docs)

Moonshine — open-source админ-панель для Laravel.

## Установка

```bash
composer require moonshine/moonshine
php artisan moonshine:install
```

Панель: [http://localhost:8000/admin](http://localhost:8000/admin)

## Основные возможности

- Resources для моделей
- CRUD из коробки
- Формы, таблицы, фильтры
- Кастомные страницы и компоненты

## Создание Resource

```bash
php artisan moonshine:resource PostResource
```
