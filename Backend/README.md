# Backend

Документация по серверной части: языки PHP, Go и Python, фреймворки Laravel, Symfony и Yii.

Клиентская часть (JS, CSS, Next.js, PM2) — в разделе [Frontend](../Frontend/README.md).

## Разделы

| Раздел | Описание |
|--------|----------|
| [PHP](php/README.md) | Справочник языка, [ООП](php/OOP/README.md), [SOLID](php/SOLID/README.md), [паттерны](php/patterns/README.md) |
| [PHP-FPM](php/php-fpm.md) | Пул воркеров, сокет, связка с Nginx |
| [Laravel](laravel/README.md) | Маршруты, Eloquent, очереди, API, тесты |
| [Symfony](symfony/README.md) | Карта [официальной документации](https://symfony.com/doc): маршруты, DI, Doctrine, Security |
| [Yii](yii/README.md) | Карта [документации Yii 3](https://yiisoft.github.io/docs/): гайд, рецепты, DI, middleware |
| [Go](go/README.md) | Язык Go: синтаксис, горутины, пакеты, сеть и базы по [спецификации](https://go.dev/ref/spec) и [Metanit](https://metanit.com/go/tutorial/) |
| [Python](python/README.md) | Основы Python: синтаксис, функции, классы, коллекции по [документации](https://www.python.org/doc/) и [Metanit](https://metanit.com/python/tutorial/) |
