# Операторы

> Источник: [Операторы | PHP Manual](https://www.php.net/manual/ru/language.operators.php)

## Арифметические

```php
<?php

$a + $b;  // сложение
$a - $b;  // вычитание
$a * $b;  // умножение
$a / $b;  // деление
$a % $b;  // остаток
$a ** $b; // степень
```

## Инкремент и декремент

```php
<?php

$i = 1;
$i++; // постфикс: вернуть, потом увеличить
++$i; // префикс: увеличить, потом вернуть
$i--;
--$i;
```

## Присваивание

```php
<?php

$a = 1;
$a += 2;  // $a = $a + 2
$a -= 1;
$a *= 3;
$a /= 2;
$a %= 2;
$a **= 2;
$s .= 'x'; // конкатенация
```

Присваивание по ссылке: `$b = &$a;`

## Сравнение

```php
<?php

$a == $b;   // равны после приведения типов
$a === $b;  // равны и тот же тип (предпочтительнее)
$a != $b;
$a !== $b;
$a < $b;
$a <= $b;
$a > $b;
$a >= $b;
$a <=> $b;  // spaceship: -1, 0, 1
```

| Оператор | Пример | Результат |
|----------|--------|-----------|
| `==` | `5 == '5'` | `true` |
| `===` | `5 === '5'` | `false` |
| `??` | `$x ?? 'default'` | значение, если не `null` |
| `?:` | `$x ?: 'default'` | значение, если truthy |

```php
<?php

$name = $_GET['name'] ?? 'guest';
$config['debug'] ??= false; // присвоить, только если null
```

## Логические

```php
<?php

$a && $b;  // и
$a || $b;  // или
!$a;       // не
$a xor $b; // исключающее или
```

`and` / `or` — то же, но ниже приоритет, чем у `=`.

## Строки и массивы

```php
<?php

'Hello' . ' ' . 'PHP'; // конкатенация

$a = ['a' => 1];
$b = ['b' => 2];
$c = $a + $b; // объединение (ключи из $a приоритетнее)
$a == $b;     // одинаковые пары ключ→значение
$a === $b;    // тот же порядок и типы
```

## Побитовые

```php
<?php

$a & $b;  // AND
$a | $b;  // OR
$a ^ $b;  // XOR
~$a;      // NOT
$a << $b; // сдвиг влево
$a >> $b; // сдвиг вправо
```

## Проверка типа и ошибки

```php
<?php

$obj instanceof User;

@file_get_contents('missing.txt'); // подавить предупреждение (не злоупотреблять)
```

## Оператор выполнения

```php
<?php

$output = `ls -la`; // оболочка ОС — опасно с пользовательским вводом
```
