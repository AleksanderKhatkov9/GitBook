# 1. Введение

> Источники: [Спецификация — Introduction](https://go.dev/ref/spec) · [Metanit — глава 1](https://metanit.com/go/tutorial/) · [Tour](https://go.dev/tour/welcome/1)

## Что такое Go

Go — язык общего назначения. Его проектировали с прицелом на системные программы: сетевые сервисы, утилиты, инструменты сборки. По спецификации он **строго типизирован**, память освобождает **сборщик мусора**, а параллельное выполнение поддержано самим языком.

Программа состоит из **пакетов**. У пакета понятные границы, поэтому зависимости подключаются и обновляются отдельно, без ручной сборки «всего дерева» руками.

Синтаксис компактный: его легко разбирает и человек, и автоматические инструменты (форматтер, линтер, IDE).

Исходный текст — Unicode в кодировке **UTF-8**. Заглавные и строчные буквы — разные символы: `User` и `user` — два разных имени.

## Где его берут

| Задача | Почему Go |
|--------|-----------|
| HTTP API | Пакет `net/http` уже в стандартной библиотеке |
| CLI | На выходе один файл, его просто раздавать |
| Воркеры и прокси | Горутина на соединение — обычный приём |
| Инфраструктура | На Go написаны Docker, Kubernetes, Prometheus, Terraform |

## Установка

Скачайте сборку под свою систему: [go.dev/dl](https://go.dev/dl/). После установки:

```bash
go version
```

| Команда | Что делает |
|---------|------------|
| `go run .` | Собрать текущий пакет и сразу запустить |
| `go build -o app` | Собрать бинарник `app` (на Windows — `app.exe`) |
| `go fmt ./...` | Отформатировать все пакеты модуля |
| `go test ./...` | Запустить тесты |
| `go mod init example.com/hello` | Создать файл модуля `go.mod` |

Онлайн, без установки: [go.dev/play](https://go.dev/play/).

## Первая программа

Файл `main.go`:

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет, Go")
}
```

```bash
go mod init example.com/hello
go run .
```

| Часть | Зачем |
|-------|--------|
| `package main` | Пакет с точкой входа. Имя `main` зарезервировано под программу, а не под библиотеку |
| `import "fmt"` | Подключить пакет форматированного ввода-вывода |
| `func main()` | Выполнение начинается здесь. Аргументов и результата у `main` нет |

Имена, которые видны другим пакетам, начинаются с заглавной буквы. `fmt.Println` экспортирован, `fmt.println` снаружи пакета `fmt` не существует.

## Точка с запятой

В формальной грамматике инструкции заканчиваются `;`. В коде их почти не пишут: компилятор вставляет точку с запятой сам, если строка заканчивается идентификатором, литералом, ключевым словом `break` / `continue` / `fallthrough` / `return` или одним из символов `++`, `--`, `)`, `]`, `}`.

Открывающая скобка `{` у функции и `if` остаётся на той же строке. Перенос её на следующую строку ломает разбор: компилятор уже вставил `;` перед `{`.
